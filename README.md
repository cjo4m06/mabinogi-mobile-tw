# 瑪奇 Mobile 台服（S0）攻略知識庫 + 符文乘區計算器

手機遊戲《瑪奇 Mobile》（Mabinogi Mobile／마비노기 모바일）台服繁中版的資料整理。
兩個部分可以分開用：

| 目錄 | 是什麼 |
|---|---|
| `index.html` | **符文乘區分配計算器** — 單檔網頁，開了就能用 |
| `skill/` | **Claude Code Skill** — 台服 S0 的完整攻略知識庫 |

> ⚠ 這是**手遊《瑪奇 Mobile》**，不是 PC 版《瑪奇》，也不是《瑪奇英雄傳》。三者系統毫無共通。

---

## 一、符文乘區分配計算器

回答一個具體問題：符文上寫「**攻擊力 +%**」和寫「**造成的傷害 +%**」差在哪，該怎麼分配。

直接用瀏覽器打開 `index.html` 即可（單一自包含檔案，無外部依賴、無網路請求）。

**它在算什麼**

社群推導的傷害結構是「同區內相加、區與區相乘」：

```
輸出 ∝ 基礎攻擊力 × (1 + 攻擊力加成總和) × 技能倍率 × (1 + 傷害加成總和) × …
```

由此可得兩個結論：

1. **甜蜜點是兩區相等。** 總量固定時 `(1+a)(1+d)` 在 `a = d` 最大（算幾不等式）。
   總量 80% 時均分比全押一邊多 8.9%；總量 160% 時多 24.6%。
2. **實務判準是往低的那區加。** 再加 1 個百分點的相對收益是 `1/(1+該區現值)`。

拿「千把劍（+24% 攻擊力）」對上「遺忘時代（+25% 傷害）」，忽略冷卻懲罰時臨界條件是
`a > 0.96d − 0.04` — 只要攻擊力區不低於傷害區，遺忘時代就贏。而防具符文幾乎全是攻擊力%，
所以多數人本來就 `a ≫ d`。

**但頁面裡最重要的是那組單選鈕。** 「遺忘時代那 25% 到底落在哪一區」沒有可靠原文能定案，
三種可能（傷害區／攻擊力區／獨立最終傷害）導出完全不同的結論，所以計算器讓你自己切換假設，
而不是替你選一個。

### ⚠ 這條公式官方從未公開

台服官網《遊戲指南》只定義了 5 個主能力值、15 個下級能力值與 14 種傷害判定，
**沒有任何計算式**。乘區結構出自韓國遊戲媒體與玩家實測整理，屬社群推導。

已知的缺口（頁面底部有完整列表）：

- 遊戲內有「文字寫傷害、實際結算為攻擊力」的符文（韓服社群稱「짭피증」），例如決鬥、安定
- 台服玩家自己做的打樁實測**一筆都不存在**，所有乘區說法都是轉述韓服
- 「攻擊力 +%」加在哪個基數（武器基礎攻擊力／面板總攻擊力）未確認
- 韓服資料多為 2025 年 4–5 月（韓服 S0）環境，與台服賽季 0 是否一致未驗證

**把它當決策輔助，不是精確數值。** 真正的答案要自己在遊戲內用木樁測：
固定目標、單發技能、每組 20~30 次取平均、一次只換一顆符文。

## 二、Claude Code Skill

`skill/` 是給 [Claude Code](https://claude.com/claude-code) 用的知識庫。安裝：

```bash
mkdir -p .claude/skills
cp -r skill .claude/skills/mabinogi-mobile-tw
```

之後問 Claude 任何瑪奇 Mobile 的問題，它會自動載入。

### 內容

| 檔案 | 主題 |
|---|---|
| `references/01` | 戰鬥能力值、14 種傷害判定、8 種持續傷害 |
| `references/02` | 18 個職業、轉職、切換職業 |
| `references/03` | 符文三層結構（固有能力／詞條／技能強化） |
| `references/04` | **各職業符文配置**（武器／防具／飾品／徽章） |
| `references/05` | 裝備基底、寶石、鍊金術、刻印強化 |
| `references/06` | 深淵、地下城、團隊副本、亡靈之塔、作業循環 |
| `references/07` | 生活技能、採集掛機點、料理、經濟 |
| `references/08` | 稱號、寵物、通行證、樂器、課金 |
| `references/09` | 賽季機制、**台韓服差異**、長期規劃 |
| `references/10` | 常見問答、社群黑話、戰鬥力自查 |
| `references/11` | 資料更新方法 |
| `data/` | 官方機率表、更新日誌、官方指南全文、符文韓文原表、技能標籤表 |
| `tools/` | 抓取工具（巴哈／Inven／Nexon Peak）與台韓辨別器 |

### 使用時最重要的三件事

1. **台服在賽季 0，韓服已到 S2。** 引用韓服資料前先跑 `python3 tools/verify.py <韓文名>` 確認台服有沒有。
   台服 S0 沒有騎士、電擊術士、暗黑術士這 3 個職業，也沒有 S1+ 的符文。
2. **飾品符文分階級。** 每職業 6 顆：菁英階 4 顆／史詩階另外 2 顆（與菁英不重疊）／傳說階 6 顆全有。
   多數社群公認的核心符文在菁英階不存在 — 晉階前先查 `data/符文階級分佈表.md`，否則會把核心符文變成別的。
3. **遊戲內顯示永遠優先。** 台版有未記錄的數值調整（已知：大劍戰士「旋轉斬」CD 被拉長）。
