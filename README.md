# 瑪奇 Mobile 符文乘區計算器

回答一個具體問題：符文上寫「**攻擊力 +%**」和寫「**造成的傷害 +%**」差在哪，下一分資源該補哪邊。

**線上版**：<https://cjo4m06.github.io/mabinogi-mobile-tw/>

> ⚠ 這是手機遊戲《瑪奇 Mobile》（Mabinogi Mobile／마비노기 모바일）**台服賽季 0**，
> 不是 PC 版《瑪奇》，也不是《瑪奇英雄傳》。三者系統毫無共通。

---

## 怎麼用

從下拉選單選出身上的符文（**武器 ×1、防具 ×5、徽章 ×1**），再填一個遊戲內看得到的
「**技能威力**」數字，就會直接告訴你補哪邊、划算幾倍。

技能威力在哪看：遊戲內點頭像 → 角色資訊 → 戰鬥能力值，找**智力**那一欄底下的三個下級能力值
（範圍強化、**技能威力**、快速技能）。它會用**與智力相同的顏色**顯示，是個絕對數字（例如 813）。

## 判準

```
攻擊力乘數 = 1 + a                     a = 所有「攻擊力 +%」之和
傷害項     = 1 + 技能威力/8500 + d      d = 所有「造成的傷害 +%」之和

再加 1 個百分點的相對收益：
    補攻擊力 → 1 / (1 + a)
    補傷害   → 1 / (1 + 技能威力/8500 + d)

⇒ 補攻擊力的條件： a < 技能威力/8500 + d
```

同一區內部相加、區與區相乘，所以**哪一區越擁擠、往那邊加就越不划算**。

## 幾個容易搞錯的地方

- **飾品符文完全不提供這兩種加成**（它們是改寫技能行為的），只有武器／防具／徽章共 7 格會。
- 徽章的「絢爛／敏捷／強烈／光暴」給的是**暴擊／連擊／強擊／破防**等特定判定傷害，
  走各自的乘區，不與通用傷害相加。
- **部分符文的韓文原文寫「주는 피해（造成的傷害）」，台服繁中卻寫「攻擊力增加」**
  （決鬥+、穩定+、狙擊+、陰險一擊、濃縮魔力）。台服翻譯反映的是**實際結算方式**，
  本頁一律以台服遊戲內文字為準。
- 技能威力的 **8500 是基準值**——要堆到 8500 才等於 +100% 技能傷害。
  一般配裝離基準很遠（如 813 只有 +9.6%），所以傷害% 的稀釋很輕微。

## ⚠ 這條公式官方從未公開

台服官網《遊戲指南》只定義了 5 個主能力值、15 個下級能力值與 14 種傷害判定，
**沒有任何計算式**。而且兩套韓服玩家推導互有出入：

| 來源 | 對「傷害%」的說法 | 導出的建議 |
|---|---|---|
| 게임톡 (2025-04-22) | 獨立乘區 | 邊際遞減 → 哪區低補哪區 |
| 나무위키 (2026-08-03) | 加進技能威力項 | 同樣邊際遞減 → **結論一致** |

分歧只影響「差幾%」，不影響「該補哪邊」。

**已知缺口**

- 台服零實測（巴哈板標題搜「實測／乘算／乘區／終傷」全部 0 篇）
- 나무위키 那頁是韓服現行版，含台服沒有的魔道抗性、賽季 2 內容
- 8500 這個基準值未在台服驗證
- 條件式符文一律以滿層計算，會**高估**
- 不含職業技能 buff、隊友 buff、稱號、食物、寵物、附魔——實際數字會比計算的高

**真正的答案要自己在遊戲內用木樁測**：固定目標、單發技能、每組 20~30 次取平均、一次只換一顆符文。

## 技術

單一自包含 HTML（`index.html`），CSS/JS 全部 inline、零外部請求、支援深淺色主題。
直接用瀏覽器開就能用，也可以下載後離線使用。
