## ★ 先看這張：分母決定「每一點值多少」

多數能力值的公式長成 `(1 + 能力值/分母) × (1 + 該類傷害%)`，**分母越小，每點越值錢**。

| 能力值 | 分母 | 備註 |
|---|---|---|
| **暴擊**（暴擊傷害） | **5,000** | 分母最小，且同時拉高機率與傷害 |
| 破防（無防備傷害） | 5,250 | |
| 絕招（充能） | 7,250 | |
| **強擊強化／連擊強化／廣域強化／技能威力** | **8,500** | 最常見的一組 |
| 絕招（傷害） | 8,750 | |
| 恢復力 | 8,750 | |
| 追擊 | 13,000 | |
| **連段強化** | **17,500** | ⚠ 分母是別人的兩倍 → **同樣數值只有一半效益** |
| 破防（破防傷害） | 25,500 | 只影響破防條累積那段 |

## 主能力值

### 攻擊力（공격력）

```
(X1 + (X2 × (1+X3)) + X4 + X5 + X6) × (1 + X7)
```

| 代號 | 內容 |
|---|---|
| X1 | 角色基本攻擊力 ＋ 升級卡 ＋ 稱號 |
| X2 | 武器攻擊力 ＋ 武器符文 ＋ 武器刻印 |
| X3 | 徽章 ＋ 徽章刻印 |
| X4 | (武器 bonus damage 倍率 × 素質) 之和 |
| X5 | 項鍊攻擊力 ＋ 項鍊刻印 |
| X6 | 寵物同行素質 ＋ 時裝套裝 ＋ 附魔等絕對值增加項 |
| **X7** | **攻擊力 % 增加之和** ← 所有攻擊力% 彼此**相加**後整體相乘 |

⇒ **「攻擊力 +24%」乘的是面板總攻擊力**，不是只有武器攻擊力。

## 輸出向能力值

### 暴擊（치명타）★ 公認效率最高

**條件**：持續傷害以外的所有攻擊

```
暴擊機率 = (((0.5 − (1000/(暴擊+2000))) + K1) × 0.75^K2) + K3
暴擊傷害 = (1.4 + 暴擊/5000) × (1 + 暴擊傷害%)
```

- K2：弩手的 거스팅 볼트 每發射一次，暴擊率 −75%
- K3：多數內容中戰鬥力達建議值以上時，**暴擊率 +30%**

> 「暴擊值越高，**是唯一同時拉高分子與分母的能力值**，所以相同投資量下**最終傷害增加效率最高**。
> 理想情況下，**暴擊值 100 ≈ 傷害增加 1%**。」

### 強擊強化（강타 강화）

**條件**：**單次傷害 ≥ 攻擊力的 40%**

```
((1 + 強擊強化/8500) × (1 + 強擊傷害%)) − 1
```

> 「因為要先滿足強擊條件，所以**受其他能力值與技能係數等因素影響**。
> **強擊條件難以滿足的職業，也有乾脆完全不投資的情況。**」

⚠ 觸發因素（原文註腳）：**寶石雕琢、技能係數、傷害增加、技能威力、是否暴擊**
（**不含**連擊、連段、廣域強化）
⇒ **注意清單裡沒有「攻擊力」**——因為門檻本身正比於攻擊力，堆攻擊力會讓傷害與門檻同步上升，**觸發率不變**。

### 連擊強化（연타 강화）

**條件**：**3 秒內維持攻擊 6 次以上**

```
((1 + 連擊強化/8500) × (1 + 連擊傷害%)) − 1
```

> 「**持續傷害、追擊、符文造成的直接傷害也能滿足條件**，所以只要配裝到位，**任何職業都能用**。」

⚠ **它是二元的**（達標就觸發），不是「次數越多加成越高」。

### 連段強化（콤보 강화）⚠ 不建議投資

**條件**：**解除輔助瞄準（assist）後攻擊**

```
((1 + 連段強化/17500) × (1 + 連段傷害%) − 1) × (E2/4)
E2：1~10 連段 = 1、11~50 = 2、51~100 = 3、101 以上 = 4
```

> 「到達最高點前有**暖機時間**，即使如此**傷害提升幅度也不大**。
> 競爭對手是強擊、連擊、暴擊，放棄那些來拿這個的好處極少，**不是該直接投資的能力值。**」

⚠ **這個才是「連段數越高、加成越高」的那個**（四階梯），常被與連擊混淆。分母 17500 是別人的兩倍。

### 追擊（추가타）

**條件**：追擊、持續傷害以外的所有攻擊

```
((1 + 追擊/13000) × (1 + 追擊機率%)) − 1
```

> 「再套用一次攻擊。技能的話 buff 等附加效果不會套用，但**屬性攻擊、破防傷害會發動**。
> 暴擊等機率變數會**重新擲一次**，連帶強擊、連擊也重新判定。
> 提升追擊機率的符文實際上被視為 **100% 的最終傷害提升**，但有例外：
> 造成追加傷害的攻擊會變成 攻擊＋追加傷害＋追擊＋(追加傷害＋追擊) 共 4 段，
> 也就是**能發揮 200% 的效率**。因此**主力技會產生追加傷害的職業，追擊效率比別的職業高。**」

### 技能威力（스킬 위력）

**條件**：平砍以外的所有攻擊

```
(((技能威力/8500) × (1+G1)) + G2 + G3) × (G4 + G5) × G6
```

| 代號 | 內容 | 運算方式 |
|---|---|---|
| G1 | 自身的「造成的**技能**傷害 %增加」之和（**符文**取得） | 對技能威力**相乘** → 技能威力越高效率越好 |
| G2 | 自身的「造成的傷害 %增加」之和 | 對技能威力**相加** → **技能威力越低效率越好** |
| G3 | 自身的［協同］造成的傷害 %增加（不可重複） | 隊友 buff |
| G4 | 敵人身上的［協同］受到傷害 %增加（不可重複） | |
| G5 | 敵人身上的弱化效果：護甲破壞（受傷 +10%，不可重複） | |
| G6 | 「以～～技能造成的傷害 %增加」之和 | 重複時合併計算 |

⚠ **8500 是基準值**：技能威力堆到 8500 才等於 +100% 技能傷害。
⚠ 原文此條缺了 `1+`（同頁強擊／連擊／廣域都寫成 `(1 + stat/8500) × … − 1`），照字面算會得出荒謬結果。

### 廣域強化（광역 강화）

**條件**：**同時打擊 2 個以上目標**

```
((1 + 廣域強化/8500) × (1 + 廣域傷害%)) − 1
```

> 「深淵、團隊副本等最終內容是**打單體首領**，所以**不是該投資的能力值**。」

### 破防（브레이크）

**條件A**：攻擊破防量條已啟動的敵人 → `破防傷害 = (1 + 破防/25500) × 技能破防傷害 × (1 + 破防傷害%)`
**條件B**：攻擊已破防的敵人 → `無防備 = (1 + 破防/5250) × (1 + 破防傷害%) + 無防備傷害%`

> 「以破防／暴擊值 5000、各自 30% 增傷為基準，**傷害結果比暴擊低約 9%，投資效率比暴擊低約 30%**。」

⚠ 灼傷／冰凍／觸電的持續傷害打破防敵人時有額外優勢（無防備 30% ＋ 屬性 7.5% = 37.5% 倍率）。
⚠ S2 起破防延展的增傷全區間砍半（台服 S0 可能是舊值）。

### 絕招（궁극기）

```
絕招量條獲得 = (1 + 絕招/7250) × (1 + 絕招量條獲得%)
絕招傷害     = ((1 + 絕招/8750) × (1 + 絕招傷害%)) − 1
```

> 「**不是主力該堆的能力值。** 魔法師、格鬥家等絕招被評為強力的職業，其絕招是 **buff 形式**，
> 所以只吃充能速度。長弓兵雖以絕招為主力，也因為被動而不投資絕招。」

## 速度向能力值

### 快速技能（빠른 스킬）

**條件**：施法／蓄力技能使用時

```
準備時間 = 施法時間 × (1 − 時間減少%) / (1 + 速度增加% + 快速技能係數)
使用時間 = 使用時間 / (1 + 使用速度增加% + 快速技能係數)
```

> 「偏好度較低，但靠**輸出循環的時間壓縮**使 DPS 上升，**冷卻有剩的職業可以適度投資。**」

⚠ 注意「時間減少%」與「速度增加%」算法不同：施法 10 秒，「時間 −50%」→ 5 秒；「速度 +50%」→ 6.4 秒。

### 快速攻擊（빠른 공격）⚠ 幾乎無用

**條件**：基本攻擊時

> 「一般來說**平砍吃不到技能威力，係數本身也極低**，不值得特意去堆。」

## 生存與支援向

### 傷害減少（피해 감소）

**條件**：受擊時。`最終受擊傷害 = 怪物傷害 / (1 + 防禦力/10000) − 傷害減少`

> 「直接扣減最終受擊傷害。**支援型與大劍戰士以外的所有職業**，都把它視為防具三選（傷害減少／要害迴避／恢復力）中的**當籤**。不過不必刻意去洗。」

### 要害迴避（급소 회피）

**條件**：受擊時。受擊時依一定機率**使傷害無效**。

### 恢復力（회복력）

```
(恢復力/8750 × (1 + 恢復力%)) × 技能係數 × 攻擊力
```

> 「影響回復藥水、技能治療量、技能護盾生成量。
> **最終治療量的提升，攻擊力的影響比恢復力更大。**
> 對支援系是核心主要能力值。**輸出職中大劍戰士會把它當主要選項**
> （另外兩個能力值妨礙其被動運用，且與自我治療有良好綜效）。」

## 最終傷害量（최종 피해량）

```
1 + (P1 × P2 × P3 × ⋯ × Pn)
```

- P1：**項鍊**部位飾品符文 超越／超越+ 時 1.5% / 3%
- P2、P3：**戒指**部位飾品符文 超越／超越+ 時 1.5% / 3%
- Pn：其他取得最終傷害量的方法，**全部彼此相乘**

⚠ **「最終傷害量」只來自飾品符文的超越刻印。** 玩家口中的「終傷」常被誤用——
一般符文寫的「造成的傷害 +%」**不是**這個類別。
