# 核心系統與戰鬥名詞字典（台服官方定義）

> 來源：台服官網《遊戲指南》→ 裝備／戰鬥能力值
> <https://tw.nexon.com/mabinogimobile/home/info/guide/>
> 這一頁是**挑符文詞條、挑防具、挑獎勵卡、挑食物的判斷基礎**。回答任何配裝問題前先看這裡。

## 1. 戰鬥能力值結構

戰鬥能力值 = **5 個主能力值** + 其下的 **15 個下級能力值**。
下級能力值在遊戲內會用**與所屬主能力值相同的顏色**顯示——這是遊戲內最快的辨識法。

| 主能力值 | 象徵 | 下級能力值 |
|---|---|---|
| **力量** | 筋力、物理力 | 強擊強化、傷害減少、破防 |
| **技巧** | 敏捷、精準 | 連擊強化、連段強化、快速攻擊 |
| **智力** | 智慧、智能 | 廣域強化（範圍強化）、技能威力、快速技能 |
| **幸運** | — | 暴擊、追擊、要害迴避 |
| **意志** | — | 追加體力、恢復力、絕招 |

### 下級能力值定義（官方原文）

| 能力值 | 效果 |
|---|---|
| 強擊強化 | 強擊傷害量增加。對**憤怒**對象造成更大的強擊傷害 |
| 傷害減少 | 承受的傷害減少 |
| 破防 | 破防傷害量增加，且對**無防備**對象造成的傷害增加 |
| 連擊強化 | 連擊傷害量增加。對**反擊**對象造成更大的連擊傷害 |
| 連段強化 | 連段傷害量增加 |
| 快速攻擊 | 基本攻擊的發生週期減少。以此值為基準，套用裝備／強化的「攻擊速度增加」，決定最終基本攻擊週期 |
| 廣域強化 | **多重打擊**傷害量增加 |
| 技能威力 | 技能傷害量增加 |
| 快速技能 | 技能施法、蓄力速度與使用速度增加 |
| 暴擊 | 暴擊發生機率與傷害量增加 |
| 追擊 | 追加造成傷害的機率增加 |
| 要害迴避 | 承受傷害減輕的機率增加 |
| 追加體力 | 體力額外增加 |
| 恢復力 | 技能及消耗品的恢復量增加 |
| 絕招 | 絕招傷害量增加，且獲得更多絕招資源 |

> **名詞不一致注意**：官方文件裡「廣域強化」與「範圍強化」、「快速技能」與「技能速度」是同一件事的不同譯法（附魔表用「廣域強化／技能速度」，能力值說明用「範圍強化／快速技能」）。回答時兩者都提一下比較保險。

## 2. 傷害判定種類（14 種）

> 一次攻擊**可能同時套用多種判定**（例如同時是強擊又是連擊）。
> 這是「該挑哪些詞條」的真正依據——**看你的技能實際會觸發什麼判定，而不是只看主能力值**。

| 判定 | 觸發條件 | 提升方式 |
|---|---|---|
| **追擊** | 攻擊時依機率再給予一次傷害 | 幸運／追擊 |
| **暴擊** | 攻擊時依機率給予更高傷害 | 幸運／暴擊 |
| **強擊** | 一次傷害達到攻擊力一定比率以上 | 力量／強擊強化 |
| **連擊** | 短時間內攻擊達一定次數以上 | 技巧／連擊強化 |
| **多重打擊** | 技能一次攻擊 2 個以上敵人 | 智力／範圍強化（附魔表寫「廣域強化」） |
| **交叉** | 技能準備中遭受攻擊，該技能以交叉狀態命中 | — |
| **迎擊** | 攻擊技能準備中的對手 | — |
| **無防備** | 攻擊已破防的對手 | 力量／破防 |
| **弱點** | 命中對方脆弱的攻擊類型 | — |
| **先制攻擊** | 攻擊體力滿值的對手 | — |
| **破防** | 填滿對方破防量條 | 力量／破防 |
| **終結** | 使對手陷入無法行動 | — |
| **技能終結** | 以技能攻擊使對手陷入無法行動 | — |
| **要害迴避** | 受擊時依機率減少部分傷害 | 幸運／要害迴避 |

## 2.5 持續傷害（DoT）八種 — 台服官方用語 ★

很多符文的效果是「賦予／偵測某種持續傷害」，彼此有連動（例如 `火炬` 只對帶**灼傷**的敵人生效）。
**台服官方只用下面這 8 個詞**：

| 台服官方用語 | 韓文 | 常見誤譯（社群攻略） |
|---|---|---|
| 持續傷害：**灼傷** | 화상 | — |
| 持續傷害：**冰凍** | 빙결 | — |
| 持續傷害：**觸電** | 감전 | 感電 |
| 持續傷害：**中毒** | 중독 | — |
| 持續傷害：**出血** | 출혈 | **創傷**（snA=1506 譯法，非官方） |
| 持續傷害：**精神** | 정신 | **恐懼**（snA=1506 譯法，非官方） |
| 持續傷害：**神聖** | 신성 | — |
| 持續傷害：**暗黑** | 암흑 | — |

> ⚠ 巴哈 snA=1506 是韓服攻略翻譯，把 출혈 譯成「創傷」、정신 譯成「恐懼」。
> **這兩個詞在台服官方文件中完全不存在**（官網全文 0 命中）。
> 引用社群攻略時要換成官方用語，否則玩家在遊戲裡搜不到。

相關符文連動（記住這幾組，配裝時很常用）：

| 你身上有 | 能觸發 |
|---|---|
| 灼傷 | `火炬`（暴擊率 +10%）、`冰凍火焰`（上衣） |
| 冰凍 | `碎冰`（追擊率 +10%）、`冰凍火焰`（下著） |
| 出血 | `吸血+`（攻擊力 +15%）、`刀刃堡壘`（戰士系） |
| 中毒 | `鎖弱／衰弱`類、`冷酷勝負師`（盜賊系） |
| 精神 | `靈魂收割者`（護甲破壞 + 攻擊力疊層） |
| 神聖 | `제물／祭品`類（回血）、祭司被動「聖戰」回神聖力 |

## 3. 防具材質 ↔ 主能力值

| 防具 | 偏向 | 對應職業系 |
|---|---|---|
| **重甲** | 力量 | 戰士系 |
| **輕甲** | 技巧 | 弓手系、盜賊系、吟遊詩人系 |
| **布衣** | 智力 | 魔法師系、治癒師系 |

> 每個職業武器都有指定的**主能力值與副能力值**（例：「智力／意志基底武器」）。
> 遊戲內在武器詳細資訊可直接看到，是最可靠的來源。

## 4. 挑詞條／獎勵卡／食物的判斷流程 ★

```
1. 看武器 → 確認職業的主能力值 & 副能力值
        ↓
2. 主能力值 → 決定防具材質（重甲/輕甲/布衣）
        ↓
3. 實際打一場，觀察技能造成的傷害判定跳什麼字
   （強擊？連擊？多重打擊？追擊？）
        ↓
4. 詞條／獎勵卡 → 依「實際觸發的判定」挑，不是只看主能力值
```

**社群公認的關鍵補充**：
> 火法主屬是智力／幸運，但技能多半帶**連擊**判定，所以也要提升「連擊強化」。
> ⇒ **防具依主能力值挑；獎勵卡與符文詞條依技能實際判定挑。**（snA=1060）

弩手範例（技巧／幸運）：
- 技巧線：快速攻擊、連段強化、連擊強化
- 幸運線：要害迴避、暴擊、追擊

## 5. 技能標籤（8 種）

每個技能都帶有標籤，符合標籤就吃得到**寶石**的強化。
⚠ **只有「異種寶石合成術」做出來的寶石才帶標籤效果**（暗光石、三重石英系、星光稜晶系）。
基礎五色寶石（紅寶石／黃玉／藍寶石／紫水晶／祖母綠）與鑽石、黑曜石**只給純能力值，沒有標籤加成**。
遊戲內查看：點頭像 → 戰鬥技能。

| 標籤 | 韓文 |
|---|---|
| 強擊 | 강타 |
| 連擊 | 연타 |
| 元素 | 원소 |
| 移動 | 이동 |
| 生存 | 생존 |
| 召喚 | 소환 |
| 輔助 | 보조 |
| 干擾 | 방해 |

寶石提供兩類效果：**〈標籤〉技能傷害強化 %** 與 **〈標籤〉技能冷卻時間減少 %**。
> 挑寶石標籤 = 看你**主力輸出技能**帶什麼標籤。全職業技能與標籤對照表見 `../data/技能與標籤-全職業.md`。

## 6. 附魔額外效果數值表（官方）

附魔卷軸有基本效果 + **0～2 個額外效果**：**抽中 0／1／2 個的機率各 1/3**，且每個額外效果的種類與數值也是均等。
卷軸來源：特定地下城、團隊副本；`[選單] → [圖鑑] → [附魔卷軸]` 可查詳細出處。

| 額外效果 | 增加幅度 |
|---|---|
| 力量／技巧／智力／幸運／意志 | 12 ～ 17 |
| 破防／傷害減少／強擊強化／快速攻擊／連段強化／連擊強化 | 17 ～ 22 |
| 技能威力／技能速度／廣域強化／要害迴避／暴擊／追擊 | 17 ～ 22 |
| 恢復力／絕招 | 17 ～ 22 |
| **追加體力** | **62 ～ 67** |

- 使用附魔卷軸時，無論既有附魔為何都會**替換**為新卷軸的效果。
- 但額外效果在持有 2 個之前會**持續累加**；達 3 個以上時可從中**選 2 個**使用。
- 附魔卷軸依 武器／防具／飾品／徽章 分專用類型。
- 分解已附魔裝備**無法取回卷軸**。
- 性能改善時，**改善目標裝備**的附魔會保留到結果裝備；**材料裝備**的附魔消滅。

## 7. 貨幣與資源速查

| 資源 | 主要用途 | 主要來源 |
|---|---|---|
| **金幣** | 刻印強化、鍊金術費用、NPC 商店 | 狩獵場「黃金堆」、販售、日常 |
| **銀幣** | 地下城／狩獵場入場（中途放棄可依進度退還） | **每 30 分 +1（離線也累積），但持有滿 100 就停止自動恢復**；上限 999，不可交易、不能放保管箱 |
| **M幣** | 儲值貨幣 | 商城 |
| **德卡** | ★ **交易所唯一交易貨幣**、商城部分商品 | 商城買「未加工德卡原石」→ 原石鍊金術。⚠ **本質是課金貨幣** |
| **符文碎片** | 刻印強化材料 | 分解符文／裝備、寶箱 |
| **精靈的痕跡** | **推職業等級**（官方唯一載明的用途）| 分解符文／重新刻印時舊符文分解、日常 |
| **職業大師勳章** | 買其他職業徽章 | 職業等級 25/35/45/55/65、重生石 |
| **深淵討伐證明** | 深淵每週獎勵上修 | 深淵重複通關 |
| **魔物討伐證明** | 向村莊官廳／管理所 NPC 兌換商品（社群推薦：遙遠的星辰印章、紫色催化劑，snA=1620） | 野外首領。⚠ **每日只有 12/18/20/22 時四個時段、出現 30 分鐘**；給大量證明的**討伐戰利品每週共 3 次**（所有首領共用），之後只有少量的基本戰利品 |
| **愛心幣** | NPC 商店貨幣；**深淵／深層地下城的 NPC 同行**也要用 | **主要來源是每日兼職**（基本／特殊／幸運機會／週末四種都給）與任務獎勵；深淵重複通關只給少量 |
| **重生石** | 重生（獲得職業大師勳章） | 活動、商城 |
| **聖水** | 淨化黑色團塊（污染超上限時自動使用；持有時自然淨化也會消耗 1 個並給獎勵） | **村莊兼職**（主要）、交易所 |
| **商城點數** | `[道具商店] → [商城點數]` 兌換道具 | 用 M 幣買部分商品時附贈 |
| **強化點數** | 累滿 100% 即確定提升刻印強化階段 | 刻印強化失敗時累積 |
| **符文重設稜鏡** | 刻印重設（洗符文詞條）的消耗品 | 遊戲內產出／兌換 |
