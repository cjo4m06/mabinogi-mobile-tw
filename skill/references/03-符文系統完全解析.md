# 符文系統完全解析（台服 S0）

符文是《瑪奇 Mobile》的**核心養成系統**。官方原話：「符文是刻印於裝備上，賦予性能與稀有度的裝備道具。」

> 一句話：**裝備的稀有度不是裝備決定的，是刻在上面的符文決定的。**
> 基底再好、寶石再滿，符文不對，這件裝備就是廢的。

---

## 0. 裝備的三個構件

一件裝備 = **符文 + 基底 + 寶石**

| 構件 | 決定什麼 | 該花多少心力 |
|---|---|---|
| **符文** | 稀有度、固有能力、戰鬥能力值（詞條）、技能強化 | ★★★★★ 幾乎全部心力 |
| **基底** | 攻擊力／防禦力數值、寶石孔數量、外觀、等級限制 | ★☆☆☆☆ 照等級換、挑數值高＋孔多的即可 |
| **寶石** | 技能標籤傷害強化／冷卻減少 | ★★☆☆☆ 時間累積，晉階 100% 成功 |

裝備欄位共 **10 件**：武器 ×1、徽章 ×1、飾品 ×3、防具 ×5。

## 1. 符文的三層結構

這是理解整個系統的關鍵。一顆符文身上有**三種完全不同、來源不同、重洗方式也不同**的東西：

```
┌─ 符文 ────────────────────────────────────────────┐
│                                                    │
│  ① 固有能力（符文能力）   ← 這顆符文「是誰」          │
│     固定不變，每個符文名稱對應一個專屬效果            │
│     ★ 挑符文的唯一判斷條件 ★                        │
│                                                    │
│  ② 戰鬥能力值（符文詞條）  ← 隨機，可重洗            │
│     武器/飾品＝攻擊11選；防具/徽章＝防禦3選           │
│     用「刻印重設」重洗                               │
│                                                    │
│  ③ 技能強化效果（符文強化技能） ← 隨機，可重洗        │
│     6 個技能欄位隨機挑 3 個，各 +2                   │
│     到鐵匠重洗，洗到自己的核心技能格上                 │
│                                                    │
└────────────────────────────────────────────────────┘
```

### ① 固有能力 — 選符文只看這個

- 每個符文名稱對應**唯一且固定**的效果，不會變。
- **武器／防具／徽章符文**：通用的戰鬥效果（例：`千把劍`＝使用劍類職業每達職業等級 40 攻擊力 +4%，最多 6 層）。任何職業都能用，只是效益不同。
- **飾品符文**：**職業專屬，直接改寫某個技能的行為**（例：戰士的 `斬擊` 讓「刃擊」永遠變成周圍圓形範圍攻擊並附加燒傷）。這是飾品符文和其他部位最大的差異。
- 「同名不同色」（例：史詩的 `落花` vs 傳說的 `落花+`）：
  - **飾品符文**：固有效果的文字敘述**一字不差**，差別只在基本效果數值 → 傳說較強。
  - ⚠ **武器／防具／徽章符文不同**：傳說「+」版**連效果敘述裡的數值本身都被上調**。
    例：`決鬥` 攻擊力 +15% → `決鬥+` **+18%**；`激戰` 最大 +15% → `激戰+` **+18%**；
    `驚異` CD −6% → `驚異+` **−8%**；`激怒` 攻擊力 +30% → `激怒+` **+36%**。
    ⇒ 不要以為武器傳說符文「只是基底數值高一點」，它的實際效果也更強。
  - ⚠ 注意：**紫色（菁英）不一定存在同名符文**。例如戰士的 `猛攻` 只有史詩以上，沒有菁英版。

### ② 戰鬥能力值（詞條）

- 官方名稱：**戰鬥能力值**；操作叫 **刻印重設**（在鐵匠 NPC 或營火）。
- **★0～★2 的符文是固定次要能力值；★3 以上才是隨機詞條。**
- **★5 史詩、★6 傳說、★6 傳說原型 有兩條詞條**，其餘（★3／★4）一條。
- ⚠ **重設時兩條會一起重洗，無法單獨鎖一條。**
- 解鎖條件：「刻印重設」需先完成 **「暴君討伐物品繳納」任務**。
- 消耗品：**符文重設稜鏡**（每次重設都要）。商城套組有販售，遊戲內亦有產出。
- 首次拿到裝備時給的詞條，機率跟重設完全一樣——所以不用覺得「原生的比較好」。

### ⚠⚠ 四個部位的詞條池**不一樣**（很多攻略都搞錯）

| 池 | 選項 | 每項機率 |
|---|---|---|
| **攻擊池（11 選）** | 快速技能／技能威力／暴擊／追擊／絕招／破防／連擊強化／強擊強化／連段強化／廣域強化／快速攻擊 | 各 **1/11** |
| **防禦池（3 選）** | **傷害減少／要害迴避／恢復力** | 各 **1/3** |

| 部位 | ★3／★4 | ★5／★6 |
|---|---|---|
| **武器・飾品** | 攻擊池 ×1 | **攻擊池 ×2** |
| **防具・徽章** | **防禦池 ×1** | **防禦池 ×1 ＋ 攻擊池 ×1** |

**這三個推論非常實用：**
1. **想堆「恢復力」（治癒師系）只能靠防具與徽章** —— 武器和飾品的池裡根本沒有恢復力。
2. **防具／徽章在 ★4 以下洗不出攻擊詞條**；要拿攻擊詞條，符文得先上到 ★5。
3. **防禦條是 3 選 1（平均洗 3 次就中），比攻擊條的 11 選 1 好洗太多** ——
   所以先把 6 件防具＋徽章的防禦條洗對，是 CP 值最高的一步。

數值（刻印強化 +0）：

| 部位 | ★3 | ★4 | ★5 | ★6 |
|---|---|---|---|---|
| 武器／飾品 | +100 | +179 | +291 ×2 | +393 ×2 |
| 防具／徽章（防禦條） | +75 | +134 | +219 | +294 |
| 防具／徽章（攻擊條） | — | — | +146 | +197 |

> 期望洗幾次的速算表見 `../data/官方機率表.md` 第 4 節。
> 各職業該挑哪些詞條 → 見 `01-核心系統與戰鬥名詞.md` 的能力值對照，以及 `04-各職業符文配置.md`。

### ③ 技能強化效果

- **前提：★4（菁英）以上的符文刻在裝備上才能做技能強化。**
- 每顆符文隨機強化 **6 個技能欄位中的 3 個**，各 **+2 級**。
- 每個欄位機率 1/6（16.6667%）均等，3 個欄位**不重複**。
- 菁英／史詩／傳說**都是 3 欄位 +2**，階級不影響技能強化的量。
- 到鐵匠可以重洗，目標是把 3 個欄位洗到自己的**主力輸出技能格**上。
- 剛好洗中指定 3 格的機率 = 1 / C(6,3) = **5%**。

> 各職業的「主要技能格」（例如戰士是 1/3/4、劍術士是 3/4/5）見 `04-各職業符文配置.md`。
> 每個技能的格位與標籤查 `../data/技能與標籤-全職業.md`。

## 2. 星級 ↔ 稀有度對照

**裝備的稀有度由符文的 ★ 數決定**：

| ★ | 稀有度 | 顏色 | 詞條 | 可技能強化 |
|---|---|---|---|---|
| ★0 ～ ★1 | 高級 | 綠 | 固定 | ✗ |
| ★2 ～ ★3 | 稀有 | 藍 | ★2 固定／★3 隨機 1 條 | ✗ |
| ★4 | 菁英 | 紫 | 隨機 1 條 | ✓ |
| ★5 | 史詩 | 粉 | 隨機 **2** 條 | ✓ |
| ★6 | 傳說 | 橙 | 隨機 **2** 條 | ✓ |
| ★6 | 傳說**原型** | 橙 | 隨機 **2** 條 | ✓ |

**原型符文（Prototype）**：地下城、深層、深淵、團隊副本可掉落／通關獲得的特殊傳說符文。
> 同名的「傳說原型 ★6」與「傳說 ★6」**固有效果相同，但基本效果（攻防數值）原型更高**。
> ⇒ 同名時**原型的基本效果較高**（官方明載）。這是數值比較，不代表取得難度。

另有 **獨特（Unique）** 裝備（例：`墮落生命之環` 戒指），走另一條線，不能刻印強化。

## 4. 符文晉階（升星）— 升到史詩／傳說的主要手段

**材料**：**成長上限、種類、階段**都相同的多顆符文。
**結果**：高一階段、**同一部位**的符文 —— 但**「拿到哪一顆」是隨機的**，不會保留原本那顆的身分。

| 你晉階的 | 會拿到 |
|---|---|
| 飾品 ★4 菁英 | 該職業**史詩階那 2 顆之一** |
| 飾品 ★5 史詩 | 該職業**傳說階那 6 顆之一** |
| 武器／防具／徽章 | 該部位符文池裡隨機一顆 |

- 失敗時**只退回一顆材料**，其餘損毀。
- 晉階時**有機率額外掉一顆傳說符文**。
- 有「**符文全部晉階**」批次功能，失敗退回的會立刻再投入。
- 催化劑可指定只對特定部位使用。

### 成功率

| 材料 | → | 成功率 | 失敗 |
|---|---|---|---|
| ★0 | ★1 | 88.2% | 10% |
| ★1 | ★2 | 83.3% | 15% |
| ★2 | ★3 | 78.8% | 20% |
| ★3 | ★4 | **49.5%** | 50% |
| ★4 | ★5 | **39.6%** | 60% |
| ★5 | ★6 | **10%** | 90% |

（另有極低機率「連續晉階」直接跳級，完整表見 `../data/官方機率表.md`。）

### 實務

- **拿備品去晉，不要拿正在裝備的那顆。** 晉掉就沒了，而且換來的不會是同一顆。
- **想要「指定」的傳說飾品符文**，深淵的**傳說飾品自選箱**比晉階可靠——晉階是 6 選 1。

### 手上一堆符文，哪些留哪些分解 ★

| 你的狀態 | 分解 | 留著晉階 |
|---|---|---|
| **配置還沒成形** | 高級、稀有 全分解 | 菁英、史詩 |
| **配置接近完成／已完成** | **菁英以下全分解** | 只留史詩 |

⚠ **批次分解前一定要先把不分解的符文「上鎖」**，不然會誤刪。

**分解會拿到兩種東西**：
- **符文碎片** → 刻印強化用
- **精靈的痕跡** → 提升職業等級用

> ★ **配置成形之後，「晉階失敗」反而變成符文碎片的主要來源。**
> 每週固定路線：週一領深淵獎勵 → 一次開完整週囤的秘術骰 → 開出的裝備全分解 → 囤的符文全部拿去晉階。
>
> ⚠ 但**不要無腦把金幣全砸在晉階上**——晉階成功率低、金幣消耗大，而金幣在遊戲各處都要用。
> **戰鬥力到約 19,000（能打團隊副本）之後，與其硬賭傳說，不如分解換碎片去堆刻印強化**：
> 此時每週深淵與團本已能穩定給秘術骰，而且可以用化石與團本貨幣**定價兌換**想要的傳說符文。
- ★5→★6 只有 10%，所以傳說飾品主要靠深淵產出，晉階當補充。

> 「成長上限」是材料配對條件之一，官方沒有進一步說明，請在遊戲內晉階畫面確認。

## 5. 飾品符文的「階級存在性」陷阱 ★★★

**每個職業的飾品符文固定有 6 種**，分佈是：

```
菁英（★4）階：4 種   ← 只有這 4 種
史詩（★5）階：2 種   ← 只有這 2 種（與菁英那 4 種完全不重疊）
傳說（★6）階：6 種   ← 全部 6 種都有
```

範例一（**樂師 악사**）—— snA=1506 原文用來示範的就是這一組：

| 符文 | 菁英 | 史詩 | 傳說 |
|---|:--:|:--:|:--:|
| 二重奏 이중주 🎁 | ● | | ● |
| 速奏 속주 | ● | | ● |
| 共鳴 공명 | ● | | ● |
| 博愛 박애 | ● | | ● |
| 兇星 흉성 | | ● | ● |
| 終章 종장 | | ● | ● |

範例二（**吟遊詩人 음유시인**）—— 注意跟樂師是**完全不同的 6 顆**：

| 符文 | 菁英 | 史詩 | 傳說 |
|---|:--:|:--:|:--:|
| 急襲 급습 🎁 | ● | | ● |
| 即興 즉흥 | ● | | ● |
| 기만（中譯待確認） | ● | | ● |
| 機智 재치 | ● | | ● |
| 嘲弄 조롱 | | ● | ● |
| 和弦 화음 | | ● | ● |

> ⚠ **snA=1506 原文把上面那張表標成「吟遊詩人」，但列出的其實是「樂師」的符文。**
> 台服攻略圈有沿用這個誤標，看到時要留意。以 `../data/符文階級分佈表.md` 為準。

**這代表什麼**：
1. 菁英階能配的就是那 4 顆，史詩階是另外 2 顆，兩組不一樣。所以「社群說的核心」在菁英階可能根本沒有。
2. **晉階不會把 A 變成更高階的 A**，而是換成上一階那組裡的隨機一顆。
   ⇒ 正在用的那顆別拿去晉；要升星就用備品。
3. 到了 ★6，6 顆全部都有，所以最終構築（飾品 3 格）就是從這 6 顆裡挑 3 顆。

> **全 18 職業的完整階級分佈 → `../data/符文階級分佈表.md`**

## 6. 符文刻印（把符文刻上裝備）

- 地點：村莊**鐵匠 NPC** 或 **營火**（也可找 NPC 戈羅）。

> ### ⚠ 動符文之前，先把武器換成主職的
> 符文晉階、以及任何會「隨機給一顆符文」的動作，**社群普遍認為會偏向給你當下職業的符文**
> （官方機率公示沒有揭露這一項，所以這是實測觀察，不是保證）。
> 但**換武器的成本是零**，所以動手前先確認手上拿的是主職武器，沒有理由不做。
> ⇒ 「戈羅的呼喚」的傳說飾品自選箱**確定**是照手上武器給職業，那個不是機率問題，是規則。
>   見 `04-各職業符文配置.md` §0.5。
- 流程：[符文刻印] → 選裝備 → 選符文。
- **刻印失敗 → 裝備被詛咒**（攻防下降、無法分解／修理／當鍊金材料）。

### 刻印成功率（武器／防具／飾品／徽章相同）

| ★0 | ★1 | ★2 | ★3 | ★4 | ★5 | ★6 |
|---|---|---|---|---|---|---|
| 100% | 100% | 60% | 60% | **40%** | **25%** | **25%** |

> 刻傳說符文有 75% 會被詛咒，這是正常的。

- 對**已刻印符文的裝備重新刻印新符文** → 舊符文被分解成 **符文碎片 + 精靈的痕跡**（不是原封不動退還）。
- 分解裝備可以取回符文，但**刻印強化階段會重置**（會退回部分符文碎片）。

### 詛咒怎麼解

1. **直接對詛咒裝備做刻印強化 → 強化成功時自動解除詛咒**（官方明載，最省，強烈推薦）。
2. **解除詛咒藥水**（可透過 NPC 以物易物取得）。

> ⚠ **聖水不是解咒道具。** 官方〈黑色團塊〉指南把聖水定義為**淨化身體污染**的消耗品，
> 全文沒有把聖水與裝備詛咒連在一起。**精靈的痕跡**官方也只有「推職業等級」一個用途。
> 但社群確實有人把兩者用在解咒流程上（snA=1243、1564 討論過三種解咒方法），
> ⇒ **如果遊戲內實際可以用聖水解咒，以遊戲內為準**；但別為了解咒去囤聖水。

## 7. 刻印強化（+0 ～ +20）

- 地點：鐵匠 NPC 或營火 → [刻印強化]。
- 材料：**符文碎片 + 金幣**。符文階級越高、強化階段越高，消耗越多。
- 上限 **+20**；獨特裝備等部分裝備不可強化。
- 成功：強化等級 +1、符文提供的能力值上升、**詛咒解除**。
- 失敗：獲得**強化點數**、**裝備被詛咒**。

### 成功率與保底

| 階段 | 成功率 | 失敗給點數 | 保底次數 |
|---|---|---|---|
| +0～+3 | **100%** | — | — |
| +4 | 80% | 40% | 3 |
| +5 | 70% | 35% | 3 |
| +6 | 60% | 30% | 4 |
| +7 | 50% | 25% | 4 |
| +8 | 40% | 20% | 5 |
| +9 | 30% | 15% | 7 |
| +10 | 15% | 7.5% | 14 |
| +11 | 10% | 5% | 20 |
| +12 | 7% | 3.5% | 29 |
| +13 | 5% | 2.5% | 40 |
| +14 | 3% | 1.5% | 67 |
| +15～+19 | 1% | 0.5% | 200 |

- 強化點數滿 100% → **不消耗材料、100% 成功**，超出部分帶到下一階。
- **強化再燃燒催化劑**：一份材料兩次嘗試（一次成功即成功），點數額外累計 1 次；點數已 100% 時無法使用。

### 強化點數的保值特性 ★

- **性能改善**：把已刻印強化的裝備當「**改善目標**」，**累積的強化點數原封不動轉移**到結果裝備。
- **刻印新符文**：累積的強化點數也**原封不動轉移**。

> ⚠⚠ **三個必須同時講的但書，漏掉會造成不可逆損失：**
> 1. **轉移的是「點數」不是「階段」。** 新舊符文階級不同時，**顯示的刻印強化階段可能往下掉**。
>    ⇒ 換 S1 世代符文時，+15 不保證還是 +15。這是「S0 該不該硬衝高強化」的核心判斷點。
> 2. **放在「材料」那一端的裝備，累積的強化點數會直接消滅。**
>    ⇒ 性能改善時把改善目標與材料放反 = 心血歸零。
> 3. **性能改善本身依既定機率會讓裝備受到詛咒。**

> ⇒ **這是全遊戲最重要的省錢技巧**：
> 一旦你開始堆刻印強化，就不要再重做一件新裝備。
> 用「性能改善」換基底、用「刻印新符文」換符文，**強化點數都會跟著走**。

## 8. 一顆符文的完整養成流程

```
1. 打本／狩獵場 拿到符文，或分解裝備回收
        ↓
2. 確認「固有能力」是不是你職業要的  ← 唯一判斷條件
   不是 → 分解成符文碎片，或留著當晉階材料
        ↓
3. 湊同種同階多顆 → 符文晉階鍊金術升星
   ⚠ 先確認這顆符文在下一階「存在不存在」（飾品符文專屬陷阱）
        ↓
4. 刻印到裝備上（★4 40%／★5・★6 25%，失敗會詛咒）
        ↓
5. 刻印強化 +0～+4 免費衝滿（順便解詛咒）
        ↓
6. ★4 以上 → 到鐵匠重洗「技能強化」，目標把 3 個 +2 洗到主力技能格
        ↓
7. 到鐵匠「刻印重設」洗「戰鬥能力值（詞條）」到職業需要的屬性
        ↓
8. 長期：繼續刻印強化 +5 以上；換更好基底時用「性能改善」保留強化點數
```

## 9. 常見誤解澄清

| 誤解 | 正解 |
|---|---|
| 「裝備等級高就好」 | 稀有度由**符文星級**決定，不是基底 |
| 「把菁英符文全部拿去賭史詩」 | 只在菁英階存在的核心飾品符文，晉階＝毀掉 |
| 「粉色（史詩）刻在橘裝上，裝備會維持橘色」 | 不會。**裝備稀有度跟著新符文走**，會變成粉色 |
| 「換符文，舊符文能留著」 | 不能。舊符文被分解成符文碎片＋精靈的痕跡 |
| 「被詛咒了要花聖水」 | 直接刻印強化，**成功就自動解咒** |
| 「重做一件新裝備比較快」 | 錯。用性能改善／刻印新符文，**強化點數會保留** |
| 「傳說一定比史詩強」 | 固有效果通常同文，但傳說**基本數值更高**；同名的話傳說較強。**傳說原型 > 傳說** |
| 「詞條可以鎖一條慢慢洗」 | ★5/★6 的**兩條詞條會一起重設**，不能單獨鎖 |
