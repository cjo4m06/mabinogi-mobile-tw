# 裝備、寶石、附魔與鍊金術（台服 S0）

> 主要來源：台服官網《遊戲指南》（裝備／寶石／鍊金術／刻印強化／附魔）＋ 巴哈 snA=1060、1243、1564
> 符文本身的機制獨立成一篇：`03-符文系統完全解析.md`

---

## 1. 裝備欄位與構成

**10 個欄位**：武器 ×1、徽章 ×1、飾品 ×3、防具 ×5

每件裝備 = **符文（決定稀有度與效果）+ 基底（承載器）+ 寶石（插槽）**

官方「良好裝備的標準」：**攻擊力／防禦力高，且寶石欄位多**。但受等級限制。

---

## 2. 基底

- 基底只提供攻防數值、寶石孔數、外觀、等級限制。
- **選法極簡單**：同等級中挑攻擊／防禦更高的；有額外寶石插槽的優先。
- ⚠ **攻防數值與寶石欄位數量是「鑑定」當下才決定的**。未鑑定的裝備看不到這兩項，要先鑑定才知道好壞——但**鑑定後就不能在交易所交易了**。
- 數值更高的基底，附帶的主能力值加成通常也更高。

### 性能改善（換基底而不損失投資）★★★

官方定義：把材料裝備的能力值套用到已刻印的裝備上。

> **操作**：`鍊金術 → 性能改善` → 把身上的裝備放上去，可用的材料會亮起。
> ★ **標有「讚」圖示的那個就是系統判定最好的選擇**，照著點就對了。
> ⇒ **卡在 2 萬戰力時的第一個檢查點**，就是有沒有把獎勵／秘術骰開到的高數值裝備注入到身上。

- 執行後：**改善對象裝備**的基本性能、名稱、外觀變成**材料裝備**的。
- 材料裝備的寶石欄位若比較多，**寶石欄位也會一併套用**。
- **已刻印強化的裝備 → 累積的強化點數原封不動轉移到結果裝備。**
- **改善對象的附魔會保留**；材料裝備的附魔消滅。
- 徽章：在已刻印的徽章上選**相同職業的大師徽章**當材料 → 可保留原有刻印與附魔，做成大師徽章。
- **有機率被詛咒。**
- 設定可調：`[選單] → [環境設定] → [遊戲] → [鍊金術]`
  - 「職業防具優先」：不符職業但性能更好也會選為材料
  - 「僅推薦職業防具」：只選符合職業材質的防具
- 自動放入材料時，**已刻印強化／菁英以上／已附魔的裝備不會被推薦為材料**（保護機制）。
- 「已配戴裝備性能改善」：一次改善身上多個部位。

> 社群建議（snA=1060）：**除非已滿級（65），否則「性能改善」等到跨等級再做**（例如 50→55 或 →60）。
> 為了一點點數值多賭一次詛咒不划算。65 等有兩套裝備可選，挑素質好的。

## 3. 寶石

### 基本

- 裝在裝備的寶石欄位 → 獲得能力值。
- **插槽數**：武器／防具**最多 3 孔**；**徽章與飾品各 1 孔**。
- 取得：地下城、**每週兼職入場的寶石地下城**、金幣商店、不祥的召喚結界、黑色坑洞。
- 操作位置：`背包 → 裝備 → 寶石頁籤`，點該寶石即可晉階或合成。同階寶石可**批次晉階**。
- **拆裝寶石沒有負擔** → 可以放心一直往上晉階。

**階段名稱對照**（會影響你看懂遊戲內文字）：

| 階段 | 對應稀有度 |
|---|---|
| 碎裂的 → 碎裂的 S | 高級 |
| **粗糙的** → 粗糙的 S | 稀有 |
| （無前綴） → S | 菁英 → 史詩 |

**同階 3 個合成 → 晉升一階。**
- **寶石晉階被社群認為是 100% 成功**（NEXON NOW 的機率公示清單裡確實沒有「寶石晉階」這一項）。不過官方鍊金術通則寫的是「依既定機率成功或失敗」，實際請以遊戲內為準。

### 異種寶石合成術 → 目標「星光稜晶」

```
① 紅寶石／黃玉／藍寶石／紫水晶／祖母綠 中，選 **3 個「相同階段」但「不同種類」** 合成 → 三重石英
② 鑽石 + 黑曜石（**須相同階段**）合成 → 暗光石
③ 三重石英 + 暗光石 合成 → 星光稜晶  ★終極目標
```
- 異種合成的材料必須是**相同階段**的**不同種類**寶石，且需「**粗糙的**」階段以上。
- 合成出來的寶石**繼承所有材料的能力值**，所以選項必然比單色寶石好；同時會隨機強化一個技能標籤。

#### ⚠ 新手最常做錯的一步：不要先把單色寶石養高再合成

```
✗ 錯：把紅寶石養到菁英階 → 才拿去合成
✓ 對：全部只養到「粗糙的」→ 立刻合成 → 先把每個插槽都塞滿粗糙的星光稜晶
```

理由有兩個：
1. **單色寶石的選項是「單一能力值上升」，效益比合成寶石差很多**。養它等於把金幣花在最沒效率的地方。
2. 階段越高，合成需要的素材量越多，**會嚴重拖慢你戴上星光稜晶的時間點**。

**正確順序**：
```
① 紅／藍／黃玉／紫水晶／綠 全升到「粗糙的」
② 取其中 3 種不同色 → 粗糙的三重石英
③ 鑽石、黑曜石也升到「粗糙的」
④ 鑽石＋黑曜石 → 粗糙的暗光石
⑤ 暗光石＋三重石英 → 粗糙的星光稜晶
⑥ 把所有插槽先塞滿 → 之後多出來的星光稜晶再彼此晉階往上推
```

> ★ **鑽石與黑曜石永遠是最缺的**，因為它們是暗光石（進而是星光稜晶）的**固定必需材料**，
> 而其他五種有色寶石可以互相替代。**看到鑽石與黑曜石一律留著，不要拿去做別的。**

### 寶石技能標籤（雕琢）

寶石提供 **〈標籤〉技能傷害強化** 或 **〈標籤〉技能冷卻時間減少**，8 種標籤各 1/8。

| 寶石 | 選項數 | 傷害強化 | 冷卻減少 |
|---|---|---|---|
| 暗光石 | 1 | +2.00% | — |  ← 只有傷害強化 ⇒ **8 選 1（12.5%）**
| 粗糙的三重石英 S | 1 | +1.70% | — |
| 三重石英 | 2 | +2.00% | — |
| 粗糙的星光稜晶 | 1 | +1.40% | −0.45% |
| 粗糙的星光稜晶 S | 2 | +1.70% | −0.55% |
| **星光稜晶** | **3** | **+2.00%** | **−0.65%** |

- ⚠ **星光稜晶系列同時有「傷害強化」與「冷卻減少」兩種效果 ⇒ 是 8 標籤 × 2 效果 = 16 選 1（各 6.25%）**，比前三種難指定。
- 重洗工具：**寶石技能雕琢器**。雕琢時**已持有的魔法效果會一併重設**。
- 晉階菁英稀有度以上的星光稜晶時，使用寶石技能雕琢器可**保留第一個選擇的星光稜晶的技能標籤**。

> **實務**：每天記得買商城道具商店裡用金幣賣的「**破碎寶石寶箱**」，積沙成塔。（snA=1060）

## 4. 附魔

- 附魔把卷軸效果**永久**賦予裝備。
- 卷軸來源：特定地下城、團隊副本。可在 `[選單] → [圖鑑] → [附魔卷軸]` 查獲得方法。
- 卷軸有基本效果 + **0～2 個額外效果**（機率與數值皆均等）。
- 使用新卷軸會**替換**基本效果；但額外效果在滿 2 個前**累加**，**達 3 個以上**時可從中**選 2 個**。
- 依 武器／防具／飾品／徽章 有專用卷軸類型。
- **分解已附魔裝備無法取回卷軸。**

額外效果數值表 → 見 `01-核心系統與戰鬥名詞.md` 第 6 節。

### 韓服附魔卷軸範例（供辨識類型）

| 類型 | 卷軸 | 效果 |
|---|---|---|
| 武器 | 火焰／冷氣／血流／無意識／毒性 | 攻擊力 +1.00%，攻擊命中 35% 機率造成對應持續傷害（CD 12 秒） |
| 防具 | 白薔薇 | 攻擊力 +100 |
| 防具 | 藤蔓／突風／貓頭鷹 | 攻擊力 +170，另加 暴擊／絕招／快速技能 +40 |
| 徽章 | 襲來／粉碎／擴散 | 攻擊力 +170，另加 連擊傷害／強擊傷害／多重命中傷害 +1.00% |
| 飾品 | 狐 | 攻擊力 +1.00%（**無附加項**） |
| 飾品 | 狐獵人／恢復／紅寶石 | 攻擊力 **+1.50%**，各自附加 技能威力／恢復／傷害減少 +40 |

（以上為韓服史詩階卷軸；台服譯名以遊戲內為準。）

## 5. 刻印強化 與 詛咒

完整機率表見 `03-符文系統完全解析.md` 第 7 節。
⚠ 「刻印重設」（洗詞條）要先完成**「暴君討伐物品繳納」任務**才開放，且會消耗**符文重設稜鏡**。

重點複述：

- +0～+4 **100% 成功**，先衝滿。⚠ 但**每一次嘗試都要消耗符文碎片＋金幣**，100% 成功不等於免費。
- 失敗會給**強化點數**，累積 100% 後**必定成功**（材料照樣要付）。
- ⚠ **刻印強化失敗時，裝備會被詛咒**（攻防下降、不能分解／修理／當鍊金材料）。+5 以後連續失敗會一直上詛咒。
- **強化成功會自動解除詛咒** → 這是最省的解咒法。
- **強化再燃燒催化劑**：一份材料兩次嘗試。
- **地點**：鐵匠 NPC、營火（各狩獵場散佈的營火點都可以）、**公會艦船上也可以**。

#### 該先強化哪個部位

```
武器 → 飾品 → 防具
```
**武器的戰鬥力與體感提升最大。** 追求規格的玩家常見水位是**武器 +15、其餘部位 +13**。

#### ⚠ +16 之後是另一個世界

- **+14→+15 只有 3%**、**+15→+16 起固定 1%**，之後不再隨階段變動。
- 階段越高，**單次要的符文碎片與保底進度條總量都同步變大** ⇒ 資源需求呈跳躍式成長。
  （挑戰 +15 每次要超過 1,000 個符文碎片。）
- ⚠⚠ **失敗會同時扣金幣與符文碎片，不是只扣材料。**
  連續失敗會把金幣榨乾到**連料理材料都買不起、武器跟工具都修不了**。
  **挑戰高階強化前，先預留修理與生活消耗用的金幣。**
- 分解已強化裝備 → **可以把刻印的符文取回來**，但強化階段重置（退回部分符文碎片）。
- 性能改善／刻印新符文 → **強化點數保留**，但⚠ **轉移的是「點數」不是「階段」，階級不同時顯示階段可能往下掉**；且**材料端的強化點數會消滅**。

### 解除詛咒的方法

1. **對詛咒裝備進行刻印強化，成功即自動解咒**（最省）
2. **到村莊鐵匠鋪使用「解除裝備詛咒」服務** —— 同時消耗**聖水＋精靈的痕跡**
3. **消除詛咒藥水** —— 任務／活動發放，可在背包直接對裝備使用

> 聖水的主要用途其實是淨化黑色團塊，別在背包裡對著裝備亂點。

## 6. 鍊金術總覽

解鎖：完成「討伐賽維爾地下城 1 層！」任務。
入口：`[選單(≡)] → [鍊金術]`，需配戴鍊金術工具。

### 四大類

| 種類 | 內容 |
|---|---|
| **晉階** | 相同種類道具 → 高一階段（符文、寶石、時裝） |
| **合成** | 不同種類道具 → 混合性質的道具（異種寶石合成） |
| **性能改善** | 在已刻印裝備上合成材料裝備，提升性能 |
| **鍊金術** | 消耗特定材料 → 製作完全不同的道具 |

### 成功／失敗

- 失敗時道具可能**被破壞或受詛咒**。
- **放在「主材料」欄位的道具，即使失敗也能安全取回。**
- **鍊金術再燃燒催化劑**：成功時有機率雙倍產出；失敗時自動再試一次。失敗可得「未知的符文碎片」配方，投催化劑後再失敗可得雙倍。

### 主要鍊金術

| 鍊金術 | 重點 |
|---|---|
| 符文晉階 | 成長上限／種類／階段相同的符文 → 高一階；失敗只退 1 顆；可額外掉傳說符文 |
| 符文全部晉階 | 批次，失敗退回的立刻再投入；可指定部位才用催化劑 |
| 寶石晉階 | **100% 成功** |
| 異種寶石合成術 | 需「粗糙的」以上 |
| 性能改善 | 見第 2 節 |
| 時裝**晉階** | 同種類、同稀有度時裝 → 高一階稀有度；晉到一定稀有度以上需商城的**魔法絲線** |
| 時裝**合成** | 2 個史詩時裝 + 傳說裁縫剪刀 → **依機率**出傳說時裝（獨特外觀）；**也可能只拿到史詩，材料照樣全消失** |
| 原石鍊金術 | 未加工德卡原石 → 德卡 |

## 7. 獨特（Unique）裝備

- 走另一條線。官方原文：「**包含獨特裝備在內的**部分裝備無法進行刻印強化」⇒ **獨特裝備整類都不能刻印強化**。
- 獨特符文的詞條：
  - **武器／飾品**的獨特 ★4/★5/★6 = +179／+291／+393，與同星級一般符文相同。
  - ⚠ **防具的獨特從 ★3 就開始有「防禦池 ×1 ＋ 攻擊池 ×1」的雙詞條結構**
    （一般防具要 ★5 才拿得到第二條攻擊詞條）。**別把好的獨特防具拿去當性能改善材料或分解。**
- 部分獨特裝備可重設的**選項數量不同**，需在遊戲內圖鑑確認。
- 台服 S0 已知範例：**`墮落生命之環`**（獨特戒指，配戴等級 65）——效果是**使用恢復藥水時，20 秒內對敵傷害 +20%**，外加追加體力 +508。**與職業無關，誰都能用。**
- ⚠ 官方特別標註「**選項數值與既有獨特裝備不同**」的只有這 6 件：
  茉麗安的恩寵、**扭曲的生命之環**、均衡的守護者、惡夢的撫觸、狂戰士的面甲、利斯塔的實戰用戰鬥靴。
- **狂戰士的面甲**效果：**造成傷害、移動速度、攻擊速度、技能速度 各 +15%**。
  ⚠ **只能靠隨機掉落，沒有保底。**
  （**「墮落生命之環」不在這份特例清單裡**，別跟「扭曲的生命之環」搞混。）

## 8. 裝備養成優先序（實務）

```
1. 先確定職業 → 確定主能力值 → 確定防具材質
2. 基底：照等級換，挑攻防高＋孔多的。未滿 65 不急著性能改善
3. 符文：優先湊「固有能力正確」的菁英符文刻上去
4. 刻印強化 +0～+4（免費，順便解咒）
5. 寶石：每天買破碎寶石寶箱，慢慢往星光稜晶推
6. ★4 以上符文 → 洗技能強化（3 格落在主力技）
7. 洗詞條（刻印重設）
8. 滿 65 後：性能改善換好基底（強化點數保留）、繼續刻印強化
9. 深淵 → 傳說＆原型符文 → 換符文（強化**點數**保留，但**顯示階段可能往下掉**）
   （團隊副本 2026-08-05 已開放）
```
