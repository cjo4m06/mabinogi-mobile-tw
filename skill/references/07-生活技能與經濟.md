## 1. 自動採集 ★★★（最重要的生活技巧）

手動採 150 次會採到崩潰。實際上有五種自動化方法。

### 方法一：活動介面（僅活動期間）

`[選單] → 活動`（PC 版按 `V`）→ 選還沒完成的採集項目 → 按「進行」→ 角色自動幹活到完成。

### 方法二：生活技能面板（隨時可用，一趟 10 次）

`點自己頭像 → 生活技能 → 選要做的（例如採蜘蛛網）→ 「尋找附近位置」`
→ 角色會自動衝過去採集。**上限一趟 10 次**，之後會站著發呆。

更快的路徑：`點角色 → 成長指南 → 生活力 → 選技能（例如伐木）→ 進行`（直接採最高級的）。

### 方法三：圖鑑掛稀有素材 ★（目前最好用的長時間掛機法）

```
[選單] → [圖鑑] → 一路點進去（約 7 層）→ 冒險日誌支援品 → 寶物材料箱
→ 選一個「稀有」的黃金系素材 → 開始採集
```

**原理**：系統會一直採到你湊滿 **10 個那個稀有素材**為止。
因為稀有素材掉率低，**採到 1 個四葉草時你可能已經順手採了 10 個藥草**——
所以掛的時間會被大幅拉長，等於變相無限採集。

**各技能該掛哪個稀有素材**：

| 生活技能 | 掛這個 | 備註 |
|---|---|---|
| 空手採集（蜘蛛網） | **黃金蜘蛛網** | |
| 藥草採集 | **四葉草** | |
| 香菇／藥草 | **黃金苔蘚** | |
| 剪羊毛 | **黃金羊毛** | |
| 伐木 | **高級木頭**（需伐木 Lv10）／**黃金金龜子** | 黃金金龜子可在**庫漢的藍箱**取得 |
| 昆蟲採集 | **黃金金龜子** | |
| 採礦 | **黃金碎屑** | 沒有的話用石塊法（見下） |
| 鋤地 | **黃金碎屑** ／ 金幣瓢蟲 | |
| 收割 | **黃金莖桿**（小麥、玉米） | |
| 撈水 | **黃金四葉草** | 撈水可以自動 |
| 釣魚 | **黃金魚** | |
| 貝殼 | **黃金碎屑** | 貝殼的採集圖示與鋤地相同 ⇒ 用鋤地系的黃金物 |

> **判斷法**：不知道某素材要用哪個黃金物？**看它的「獲得方法」圖示屬於哪個採集動作**，
> 圖示跟鋤地一樣就用鋤地系的黃金物。（snA=600）
> ⚠ **採到黃金系素材時千萬不要分解／賣掉**，那是掛機的鑰匙。

#### 「掛的鑰匙」用完了怎麼辦——自己生產

掛機用的稀有素材本身也可以量產：

| 缺什麼 | 去製作頁籤掛這個 ×100 |
|---|---|
| **石塊** | 專業營火 |
| **獨角仙** | 強擊藥水 |
| **四葉草** | 暴擊藥水 |

#### 長莖／植物纖維的 150 個掛法 ★

```
加工 → 布料加工 → 植物纖維 → 選「長莖」
```
用「製作需求反推」的方式掛，**數量上限跟著配方需求走**，比直接點素材（一趟 10 個）多很多。
> 韓服在 2025-08-25 改版後可以一次掛到 150 個。**台服的上限請在遊戲內確認**，介面會顯示可設定的數量。

⚠ **採滿之後，必須把手上的長莖全部賣掉才能再掛下一輪。**
賣掉的可以用商店的「**再購回**」買回來，掛約 30 分鐘後回去一次買回即可。
> 再購回的限制：**販售清單超過 30 筆，或超過 1 小時，就買不回來了。**

#### 黃金材料的專用掛法

```
背包 → [物品] 頁籤 → 搜尋「黃金」→ 點該材料 → [取得方法] → 開始採集
```
黃金材料掉率極低，實測**可以連續自動採集 3 小時以上**。
⚠ **掛之前先把角色移動到「那個材料會產出的地區」**，隨便找地方掛會一直採到你不要的東西。

> 💡 **掛採集時把武器換成劍術士的長劍**——長劍有移動速度加成，是所有武器裡跑圖採集最快的。

### 方法四：好友合作任務（萬用）

透過**好友的合作任務**，幾乎所有採集都能掛。
- **1500 次用完還有 1500 次**，看起來會一直累加。
- ⚠ 缺點：除了裝水等固定重生資源點外，**無法指定單一素材集中採**（挖一挖礦就跑去旁邊抓蟲）。
- ⚠ 裝牛奶似乎不行；撿雞蛋被飛踢後會斷掉。
- ⚠ **不要亂加別人的採集合作挑戰**（snA=1484）。

### 方法五：製作/加工需求反推（半自動）

`製作／加工 → 點目標材料（例如樹液）→ [獲得方法] → 右邊出現任務欄`
→ 角色會一直採到 8～10 個，或直到工具燃盡。
**更快**：直接**點背包裡的稀缺物**（例如練剪羊毛就點「高級羊毛」）讓他慢慢做。

### 沒有黃金碎屑時的採礦替代法（石塊法）

```
製作 → 拉到最底的「道具製作台」→ 再拉到底「熟練營火套組」
→ 可建立 10 次任務 = 剛好需要 100 個石塊
→ 跑到礦點建立任務 → 掛十幾分鐘
→ 回來把石塊賣掉，重新建立任務，繼續掛
```

### 掛機注意事項

- 採集會**消耗工具耐久**，掛之前**多帶幾把工具**，可以連掛好幾小時。
- 採到一半停住：可能只是素材還沒重生，過一陣子會自動接續。
- 有時採 6 個或 8 個就停，是正常的（素材點數量／重生問題）。

## 2. 工具與加工台

### 工具（最重要的早期投資）

> **極力推薦一開始就先挖礦囤鋼錠，自己做進階工具**（所有工具都需要鋼錠）。
> 進階工具的**採集收成量是 2～3 倍**。多做幾把放身上，就不用一直修、不用手動整理雜貨店那些破爛工具。
> **越早做好工具，複利收益越好，也越省時間。**（snA=600）

`成長指南 → 生活力 → 推薦工具` 可以看目前等級能裝的最好工具。

**生活道具共 4 階**：

| 階級 | 需要角色等級 | 取得 |
|---|---|---|
| 入門用 | Lv.5 | **商店直接買** |
| 生活道具（綠） | Lv.25 | 多用途製作台自製 |
| 改良的（藍） | Lv.45 | 多用途製作台自製 |
| 精細的（紫） | Lv.75 | 多用途製作台自製 |

階級越高，加的生活力越多。

### 3 等加工台製作書兌換路徑（snA=1181）

所有 3 等製作台都需要對應的製作書才能使用：

| 加工台 | 需求道具 | 取得方式 | 兌換 NPC |
|---|---|---|---|
| 金屬加工台 | 煤炭 ×20 | 挖煤礦 Lv5 | 庫漢地區・阿爾米斯 |
| 木材加工台 | **幼蟲 ×5** | 伐木 | 杜加德走廊・特蕾西 |
| 皮革加工台 | 布料+ ×5 | 布料加工 | 杜加德走廊・艾爾文 |
| 布料加工台 | 幽靈螢火蟲 ×2 | 狼之森林（一般難度）狩獵隨機掉落 | 杜巴頓・西蒙 |
| 藥品加工台 | 毒囊 ×3 | 狼之森林（一般難度）狩獵隨機掉落 | 庫漢地區・基利安 |
| 食材加工台 | 麵粉 ×10 | 食材加工 | 提爾克納・凱琳 |

> ⚠ **幼蟲不要賣！**（snA=1028）伐木掉的幼蟲看起來像垃圾，但木材加工台升 3 等需要 5 個，而且不好收集。
> **木材加工升完再賣。**

其他已知：
- 樹液取得困難 → 可用來生產高級木、提升工具台等級（snA=741、1095）
- 食物製作台 Lv2 升級方法（snA=621）

## 2.5 公會船艦的四大加工品 ★

公會船艦（**團隊副本的移動工具**）開放後追加的四種加工品。
這些是**全遊戲最吃生活技能的產物**，製作時間也很長，通常要整個公會分工。

| 加工品 | 加工設施 | 配方 | 備註 |
|---|---|---|---|
| **焦油** | 金屬加工設施 | 原木 ×50 ＋ 黏土 ×25 → **5 個** | 原木＝伐木、黏土＝鋤地。最好取得的一種 |
| **膠** | 藥品加工設施 | **上級生皮 ×30** ＋ 裝水的瓶子 ×10 → **5 個** | 卡在上級生皮，見下表 |
| **繩索** | 布料加工設施 | **植物纖維 ×45** ＋ 蜂蠟 ×4 → **3 個** | 植物纖維由收穫得到的「**長莖**」製作 |
| **厚布料** | 布料加工設施 | — | 羊毛可靠「黃金羊毛」無限刷，**四種裡最容易的** |

- **膠**要「**藥品加工設施 Lv.2**」以上才能做，一輪 5 個約 **2 小時**。
  「裝水的瓶子」快速取得：雜貨店買**空瓶** → 食物製作選單掛「**蒸貝**」10 次，一輪可一次採到 **50 瓶**。
- **蜂蠟**（繩索用）：鄧巴頓－華特、班霍爾－基爾摩，**各每角色每週 30 個、單價 3,600 金**。
- ⚠ **繩索是四種裡最耗時的** —— 500 個繩索換算下來要超過 10 萬個「長莖」。

### 上級生皮的取得（膠的瓶頸）

| 管道 | 內容 | 頻率 |
|---|---|---|
| 商店購買 | 鄧巴頓・華特／庫漢・科納，**每張 600 金，各最多 30 張** | 每週 |
| NPC 以物易物 | 杜加德走廊・特蕾西：**原木 ×10 換 1 張**，最多 10 張 | 每日 |
| NPC 以物易物 | 鄧巴頓・內莉絲：**銅礦石 ×1 換 1 張**，最多 10 張 | 每日 |
| 分解 | **最上級生皮分解 → 上級生皮，1:1**。最上級生皮可向**班霍爾－基爾摩**買，900 金／每週 30 個 | 隨時 |
| 狩獵場任務 | 狼之森林／女神庭園／冰霜峽谷 完成任務給 | — |

> ⚠ **最上級生皮不要全部分解**，後續階段可能會直接要最上級生皮。
>
> 💡 **小號搬運技巧**：**生皮類不能放共用保管箱，但加工成「膠」之後就可以。**
> ⇒ 讓小號負責跑商店購買與以物易物、就地做成膠，再搬給主角，效率差很多。

## 2.8 分享料理（打副本前一定要吃）★

### 機制

- 料理有「自己吃」和「**分享吃**」兩種效果，**不一樣**。
- **分享效果要 2 人以上在營火旁邊分享才會觸發。**
- ⇒ 打深淵／團隊副本前，全隊在營火前吃一輪，是免費的戰力。

### 賽季 0 的分享料理

**菁英級共 5 種，基礎效果都是「全能力值 +85」，差別只在營火分享的特殊效果：**

| 料理 | 分享效果 |
|---|---|
| **鱸魚辣湯** ★主力 | 10 分鐘內，**依隊伍人數**每人 攻擊力 +120、防禦力 +120 |
| **鯖魚與鮭魚排** | 5 分鐘內，**依隊伍人數**每人 攻擊力 +1% |
| **鯰魚炸魚薯條** | 分享後**直接把絕招量表充滿** |
| 白肉魚嫩煎 | 5 分鐘內每 10 秒回復 1% 體力 |
| 馬賽魚湯 | 5 分鐘內，自己倒下時回復其他隊員 10% 體力 |

**史詩級只有 1 種**：

| 料理 | 效果 |
|---|---|
| **大晚宴：不滅之火的紅酒燉牛肉** | 基礎 **全能力值 +175**；分享後 10 分鐘內 **攻擊力 +500**，且戰鬥中每 5 秒對周圍 4m 內敵人造成持續傷害（燒傷）。營火分享有專屬過場動畫 |

### 該帶哪個

```
4 人以下 → 大晚宴（固定值，不吃人數）
4 人以上 → 鱸魚辣湯（人數加成 ×4 以上，而且持續 10 分鐘）
```

- **鯖魚排只持續 5 分鐘，鱸魚辣湯 10 分鐘** ⇒ 泛用性鱸魚辣湯更好。
- ⚠ **人數加成型料理對低戰力角色幾乎沒用**——加的是比例／隊伍規模，底子不夠時差距很小。
- 現在的副本普遍都有補師，**回復向料理（白肉魚嫩煎、馬賽魚湯）實用度低**，優先帶攻擊向。
- ⚠ **料理增益有時限**，團隊副本要在**最後一個營火房**（緊鄰王房那個）才吃。

### 賺金幣的主要路徑

1. **狩獵場「黃金堆」** — 官方成長指南直接寫明這是金幣主要來源
2. **閃耀洞穴**（週一、週四的週幾地下城）— 產金幣
3. **交易所** 賣可交易道具（收德卡）
4. **特殊兼職**（需生活會員）— 黃金錠堆／黃金錠捆
5. **幸運機會兼職** — 大量金幣與聖水
6. 生活素材加工後販售
7. 需課月卡的額外賺錢法（snA=1618）

## 4. 交易所

`[選單(≡)] → [交易所]`，**用德卡交易**。

| 規則 | 內容 |
|---|---|
| 可交易道具 | 圖示上有「可交易」標示的才行 |
| ⚠ **已鑑定的裝備無法交易** | 即使未鑑定時顯示「可交易」，**鑑定後就變成不可交易** |
| 交易次數 | **1 次**。次數歸 0 後原則上不能再交易 |
| 行情 | 每 12 小時反映 3 天內交易算平均價，可設定的售價範圍依平均價而定 |
| 手續費 | 領取貨款時自動扣，**由賣家全額負擔** |
| 可買到什麼 | **聖水可以在交易所買**，這是常備聖水最直接的補給管道 |
| 登錄費 | 上架時收的保證金；正常成交或期限屆滿會退還，**中途取消不退** |
| 貨款 | 傳送至信箱，可立即領取 |

> **社群觀點（snA=1321）**：目前**符文不能在交易所拍賣**，社群有不少人認為這限制了經濟流動性。

## 7. 背包與倉庫

- 背包**不是格子數限制，是「重量」限制**：每件物品各有重量，超過上限角色會**無法移動**。
- 基本可用到 **400**，要再往上必須裝備「**背包**」道具（工具–背包欄位）。
- **背包哪裡買（無課管道）**：
  - 道具商店的「**金幣**」頁籤
  - 村莊旅館的「**愛心幣**」兌換商店
  - **地下城 n-3 的貓商人**
  - 以上都有高級／稀有等級的背包
  - 付費等級由低到高：菁英 → 史詩 → 傳說
- 換上比目前更高等級的背包就會提高上限。**實測上限**：3 種傳說背包＋傳說等級的馬同行 → **重量上限 2,090**。

### 背包爆了怎麼清（整理鍵的正確用法）★

整理鍵在**背包畫面右下角**。判定基準可在 `環境設定 → 遊戲` 調整。

```
① 先關掉「果斷整理」，只勾「黃金及雜物」
   → 這類只會挑純換錢用的道具去賣，可以無腦按，不用怕誤刪
② 進「詳細整理」，取消勾選「一般」
   → 畫面就會列出各部位裝備，再針對武器／防具／飾品處理
③ 按右上「全選」後，把「戰鬥力最高且沒鑲符文」的那件取消勾選留下來
   → 每個部位留一件就好，之後要拿它做「性能注入」
   （還在衝戰鬥力的話，改留鑲綠色符文的高級裝備中戰鬥力最高那件）
④ 做「符文晉階」把下位符文消耗掉，可以再清一批
```

- 「**果斷整理**」用更寬鬆的基準，清得快但**可能連要用的一起分解**，謹慎使用。
- 空間還是不夠時可以按「材料整理」把材料減半，但**事後常會後悔** ⇒ **優先用倉庫**。
- ⚠ **超重的懲罰不只是拿不了東西——「採集」與「進入地下城」等行動會受到限制。**
  這對長時間掛機自動採集是致命的：包滿了採集就停了，掛機等於白掛。**掛機前先清包、先裝背包。**
- ⚠ **兩種倉庫別搞混**：
  - **保管箱** = **個人**金庫，**同帳號其他角色無法存取**
  - **公用保管箱** = 可跨角色（同帳號、同伺服器）
- 不能放進去的不只銀幣，**金幣、M幣、寵物**等也不行。
- 整理心得：snA=883（「您各位的包包強迫症……由我來拯救！」）

## 7.5 生活力：最多人搞錯的一點 ★

### ⚠ 「加工」不會增加生活力，只有「製作」才會

鐵錠、木材、皮革、布料、藥品、食材 —— **這 6 種加工通通不加生活力。**
一直掛加工卻發現生活力不動，原因就在這裡。

**提升生活力的 6 條途徑**：
1. 做生活行動
2. 生活技能升級
3. 穿戴**生活道具**
4. 穿戴**背包**
5. **製作**（不是加工）
6. **製作台／加工設施升級**

### 生活技能怎麼練最快

- **採「自己能採的最高等級採集物」** —— 生活技能經驗值更多，升級最快。
- 長期經營的話**優先練 砍樹、採礦、剪羊毛** —— 這三項的產物正好用在製作台與加工台升級上。

## 8.5 單人玩家（solo）路線

**戰鬥內容偏協力，生活內容則完全可以一個人推進** ⇒ 單人玩家的核心是**主攻生活**。

```
素材端：採集 ／ 伐木 ／ 採礦
製作端：鍛造 ／ 木工 ／ 料理
目標  ：賺德卡 → 用德卡買禮包 → 達到準免課
```

生活賺錢需要投入大量時間，這對單人玩家反而是優勢。

> 另外「**主帳＋分身，每週把銀幣與魔族貢品用掉去跑本**」的作業循環對單人玩家一樣成立，
> 下位材料的供給其實相當充裕，不必擔心單人拿不到素材。

## 9. 實務優先序（新手 → 中期）

```
1. 先把「採礦」練起來 → 囤鋼錠 → 做進階工具（採集量 ×2~3）
2. 多做幾把工具帶身上，開始用「圖鑑掛稀有素材」長時間掛機
3. 蒐集 3 等加工台製作書的兌換材料（幼蟲、煤炭、毒囊、幽靈螢火蟲…）
   ⚠ 幼蟲別賣
4. 每天做兼職（金幣、聖水、愛心幣、生活經驗）
5. 每天進週幾地下城（週一四金幣／週二五寶石／週三六催化劑；週日自選）
   前提：先接 **32 級以上的每週兼職**，**每天只能入場一次**
6. 每天商城買破碎寶石寶箱（金幣購買）
7. 身上常備聖水 → 黑色團塊**累積夠多時**，自然淨化會自動消耗聖水並給獎勵（團塊少時不會觸發）
```
