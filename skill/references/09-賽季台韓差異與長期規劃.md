# 賽季機制、台韓差異與長期規劃

> 資料時點：**2026-08-05（8/5 改版後）**。台服 **2026-07-21 開服**，目前約兩週，處於**賽季 0（S0）**。
> 韓服（원본）已進行到 **S2**。
> ⚠ 這一頁的時效性最短，回答時務必先確認「今天是什麼時候、台服現在到哪」。

## 1. 「賽季」到底是什麼

### 官方確認的部分

台服官方文件中，「賽季」出現在兩個地方：

1. **符文帶有賽季標記**
   官方鍊金術說明寫：「在遊戲中投入**賽季 0 史詩(★5)、傳說(★6) 等級符文**作為材料時，
   所顯示的預期結果值圖示為演出用圖片。」
   ⇒ **符文是按賽季分代的。S0 符文、S1 符文、S2 符文是不同世代。**

2. **深淵排名賽季** — **2026-08-05「地獄1」開放後開始計分**
   分數**只來自地獄難度**：難度越高、通關時間越短分數越高；重複通關可加分（累計到第 30 次）。
   ⚠ 戰鬥力低於隊伍平均 90% 的角色分數 −10%。詳細規則見 `06-副本深淵與作業循環.md`。
   （規則本身：賽季結束時各伺服器、各職業前 10 名可獲獎勵，以結束時點上午 7 點的分數為準，透過角色郵件發放。
   獎勵是**外觀椅子，且只有 30 天期限**，沒有戰力回報，不值得為它調整資源配置。）

### 社群理解與擔憂（非官方）

> 「無預警展開新賽季，**符文裝備全部換掉**！」（snA=495，引用韓服玩家一年心得）

**準確的說法應該是**：
- 新賽季不是「重置帳號」，而是**推出更高世代的符文**（S1、S2…），
  新世代符文的**基本效果數值更高**，舊賽季的符文被 power creep 淘汰。
- ⚠ 以上是**社群依韓服經驗的推測**，官方未公布台服賽季政策。實際影響請以官方公告為準。
- ⚠ **官方目前沒有公布台服的賽季長度或賽季轉換政策。**
  回答時應該說「官方尚未公布，社群依韓服經驗推測」，不要講死。

### 對台服玩家的實務結論

```
S0 期間的投資中，哪些會保值、哪些會被賽季稀釋：

【保值】
  ✓ 稱號「持有效果」（累積職業等級）→ 帳號永久加成，跨賽季不變
  ✓ 職業等級（千把劍、領悟等符文靠這個生效）
  ✓ 寶石（星光稜晶）→ 不是符文，不隨賽季換代
  ✓ 生活技能等級與工具
  ✓ 遊戲理解與操作

【會被稀釋】
  ✗ S0 傳說符文本身
  ✗ 押在單一符文上的極高刻印強化（但強化「點數」可轉移，見下）

【緩衝機制】
  ~ 刻印強化「點數」在【性能改善】與【刻印新符文】時原封不動轉移
    ⇒ 換 S1 符文時，S0 累積的強化點數不會白費
```

> ⇒ **S0 的最佳資源配置：優先堆「跨賽季保值」的東西**（累積職業等級／稱號／寶石／生活），
> 符文追到「能舒服打完當期內容」即可，不必在 S0 硬衝 +15 以上。

### 已知台版數值調整

| 項目 | 差異 |
|---|---|
| **大劍戰士「旋轉斬」** | 台版 CD 被拉長（例：4 秒 → 20 秒），連招循環被破壞。**「旋轉」不再是優選**（snA=1506 補充區） |

> ⚠ 一定還有其他未被記錄的調整。**只要韓服攻略講的東西和你在遊戲裡看到的不同，以遊戲內為準。**

### 稱號計算方式

- **台服的持有效果稱號是「帳號通用」**（已確認），累積職業等級以帳號計。
- ⇒ **開滿分身衝累積職業等級是有效投資**，這也是全 Skill 最保值的長期目標。

## 4. 社群對這款遊戲的評價（誠實版）

回答使用者「這遊戲值得投入嗎」時，應該同時給出兩面。

### 優點（韓服玩家一年心得，snA=495）

- 音樂與整體氛圍表現不錯
- 前期的感性與演出品質很好
- 對原版《瑪奇》玩家來說，重製版 NPC 很有懷念感
- 某種程度保留了原作的獨特氛圍
- 有生活系 MMORPG 的感覺
- 整體風格偏休閒輕鬆
- **裝備系統在課金玩家與無課／小課玩家之間的平衡，做得相當好**（snA=1125 原文評價）

### 缺點

> ⚠ **下表六列全部出自 snA=495 引用的「韓服玩家一年心得」，講的是韓服長期體驗，不是台服現況。**
> 台服開服才兩週，很多項目（更新頻率、平衡調整方向、賽季處理）**尚無足夠樣本可判斷**。

| 面向 | 內容 |
|---|---|
| **職業平衡** | 差距非常嚴重，長期偏向特定 META 職業且幾乎不改；相同資源投入下性能差距巨大；後期有「被迫玩 META 職業」的感覺 |
| **平衡更新頻率** | （韓服）大約**兩個月才一次**，內容通常只有一行；方向偏削弱而非加強。⚠ **台服不同**：官方在台港澳 Showcase 已公開**每月更新計畫**，並表示上市後維持**每週更新節奏** |
| **養成結構** | 符文／刻印／強化是 **RNG 上面再套 RNG**，疲勞感非常重，過度依賴低機率 |
| **內容深度** | 內容不足、更新速度慢；副本不斷堆數值加難度（韓服在非常困難之上還有地獄 1～7 級；**台服 S0 只到非常困難**） |
| **作業感** | 每日／每週必做內容太多但深度不足，重複農裝結構單調 |
| **賽季** | 無預警展開新賽季，符文裝備要重做 |
| **課金商品** | 通行證＋會員制度＋階段性禮包，種類多到複雜，有炒短線觀感（snA=1273） |
| **時裝／染色** | 低稀有度時裝**不能染色**，要升上去才行（snA=1273） |
| **滿級後空虛** | 副本難度低＋自動化程度高 ⇒ 缺乏追求裝備的動機與成就感（snA=1125，⚠ 該文寫於深淵開放前，現況已改善） |

> ⚠ **時序注意**：snA=1125、1273 這類「滿級沒事做」的心得，多寫於 **7/29 深淵開放之前**。
> 深淵與亡靈之塔（7/29）、團隊副本與深淵地獄1（8/5）上線後，滿級後的內容量已明顯改善。引用這些批評時要註明時點。

## 5. 長期規劃建議

### 65 級之前

```
1. 跟主線推到 65（會自然解鎖大部分系統）
2. 職業等級 35 → 領該職業的核心飾品符文成就獎勵（每帳號一次）
3. 裝備先 +7 頂著就好，不用急著 +10
4. 生活：先練採礦囤鋼錠 → 做進階工具（採集量 ×2~3）
5. 開始蒐集 3 等加工台的製作書材料
```

### 65 級之後（現階段主軸）

```
1. 解鎖深淵：完成 [跟隨影子] → 討伐克拉瑪 → [向那深邃黑暗的彼端]
2. 每週深淵打「非常困難」，**通關戰利品 3 次**用滿 → 傳說符文、深淵的化石
   官方建議戰鬥力：入門 14,337／困難 16,358／非常困難 18,380
3. 野外首領每週 3 次討伐戰利品 → 魔物討伐證明買滿印章與催化劑
4. 亡靈之塔每天 20 次（免費，每日 20 次挑戰）
5. 「通往深淵的黑色坑洞」不消耗次數，能刷就刷
6. 深淵**地獄1**（8/5 開放）—— 這是深淵排名唯一的計分來源
```

### 帳號級長期投資（最保值）

```
1. 【最高優先】累積職業等級 → 持有效果稱號
   675 → 多才多能（全帳號 攻+275 防+275）
   975 → 萬能天才（+最大體力 800）
   1,205 → 全能者（⚠ 台服 18 職上限 1,170，目前達不到）
   ⚠ **累積方式是「每個職業取所有角色中的最高等級再加總」**，分身要分攤不同職業，
      重複練同一職業沒有加成。做法見 `08-稱號寵物與其他系統.md`

2. 【次高】6 個用劍職業推到 40 級 → 千把劍滿層（攻擊力 +24%）
   戰士、大劍戰士、劍術士、冰霜術士、盜賊、雙刀客

3. 【穩定累積】寶石往星光稜晶推（晉階 100% 成功）
   每天買破碎寶石寶箱

4. 【穩定累積】刻印強化點數（換符文／換基底時會保留）

5. 【耐心工程】飾品符文 3 顆傳說（或傳說原型）
```
