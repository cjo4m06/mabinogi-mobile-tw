# 常見問答與判斷準則

給 AI 用的快速決策表。回答前先確認**職業**與**目前進度（等級／已解鎖哪些內容）**。

## A. 符文相關

### Q：我拿到一顆符文，要留還是分解？

```
是飾品符文嗎？
├─ 是 → 看它改寫的技能，是不是我這職業的主力技（查 04 的「主要技能格」）
│        ├─ 是 → 留。特別是「35 級成就送的那顆」絕對不能丟
│        └─ 否 → 留著當同階晉階材料，或分解成符文碎片
└─ 否（武器/防具/徽章）→ 查 04 第 3 節的通用符文表
         ├─ 在表上且星等 ★★★★ 以上 → 留
         └─ 不在表上 → 晉階材料 or 分解
```

### Q：菁英符文要不要晉階到史詩？

**先問：這顆符文在史詩階存在嗎？**
- 飾品符文：**菁英階 4 種、史詩階 2 種、完全不重疊**（全 18 職業已確認）。
  遊戲內 `圖鑑 → 符文` 用顏色就能判斷：**紫＝菁英、粉＝史詩、橙＝傳說**。
  只在菁英階存在的核心符文 → **晉階＝毀掉它**，因為結果一定是你不要的那 2 顆之一。
- 而且 ★4→★5 成功率只有 **39.6%**，★5→★6 只有 **10%**。
- ⇒ 早期先用菁英階的核心符文；傳說版本靠深淵獎勵／傳說選擇箱拿。

### Q：詞條（戰鬥能力值）怎麼洗？該洗什麼？

- **怎麼洗**：鐵匠 NPC 或營火 →「刻印重設」。需先完成「暴君討伐物品繳納」任務，每次重設消耗**符文重設稜鏡**。
- ⚠ **部位不同，詞條池不同**：
  - **武器／飾品** → 攻擊池 11 選，各 1/11：快速技能／技能威力／暴擊／追擊／絕招／破防／連擊強化／強擊強化／連段強化／廣域強化／快速攻擊
  - **防具／徽章** → **防禦池 3 選，各 1/3：傷害減少／要害迴避／恢復力**（★5/★6 才多一條攻擊池）
  - ⇒ **恢復力／傷害減少／要害迴避 只能從防具與徽章拿；武器飾品洗不出來。**
  - ⇒ 防禦條 1/3 很好洗（平均 3 次），攻擊條 1/11（平均 11 次）
- ⚠ **★5／★6 有兩條詞條，重設時一起重洗，不能單獨鎖**
- **該洗什麼**：查 `04-各職業符文配置.md` 速查總表的「推薦詞條」欄
- **通用判斷法**：實際打一場，看跳出來的傷害判定是什麼字（強擊？連擊？多重打擊？追擊？），照那個挑

### Q：技能強化怎麼洗？

- **前提：★4 以上的符文刻在裝備上才有**
- 6 個技能欄位隨機挑 **3 個**，各 **+2**，每格 1/6 均等
- 到**鐵匠**重洗，目標是把 3 格洗到自己的**主要技能格**（查 04 總表）
- 剛好命中指定 3 格的機率 = **1/20 = 5%**

### Q：粉色（史詩）符文刻在橘色（傳說）武器上，武器會變什麼顏色？

**變粉色。** 裝備的稀有度**完全由當前刻印的符文星級決定**。

### Q：換符文，舊符文能保留嗎？

**看你用哪個做法：**
- **在原裝備上刻新符文** → 舊符文被分解成「符文碎片 + 精靈的痕跡」，**拿不回來**。
- **「符文分離」：分解整件裝備** → **可以把已刻印的符文回收回來**，代價是刻印強化階段重置（會以材料道具部分返還）。
  ⇒ 「我有一顆好符文但基底很爛」時，這才是正確做法。

刻印強化「**點數**」在刻新符文／性能改善時會轉移，但⚠ **轉移的是點數不是階段，顯示的強化階段可能往下掉**。

## B. 裝備與強化

### Q：裝備被詛咒了怎麼辦？

**直接對它做刻印強化，成功會自動解除詛咒。** 這是最省的方法。
其次才是聖水／精靈痕跡／消除詛咒道具。

刻印失敗率本來就高（★5/★6 有 **75%** 會失敗＋詛咒），這是正常流程。

### Q：刻印強化衝到幾？

- **+0～+4 是 100% 成功**，一律衝滿。⚠ 但每次仍要消耗符文碎片＋金幣，不是免費。
- +5 之後成功率遞減：**升到 +5** 是 80%、**升到 +10** 是 30%、**升到 +11** 是 15%、**+16 以上**只有 1%。
- 但**失敗會給強化點數，滿 100% 必成**（+4 最多失敗 3 次、+10 最多 14 次、+15 以上要 200 次）。
- **S0 階段的實務建議：先 +7 頂著，把資源投在累積職業等級與稱號上**（snA=1353）。

### Q：要換更好的基底，之前的投資會不會白費？

**不會。** 用**「性能改善」**鍊金術：
- 累積的**刻印強化點數原封不動轉移**
- 改善目標裝備的**附魔保留**（材料裝備的附魔消滅）
- 材料裝備的**寶石欄位若更多，也會一併套用**

⇒ **一旦開始堆刻印強化，就不要重做新裝備。** 用性能改善換基底、用刻印新符文換符文。

### Q：什麼時候該做性能改善？

**除非已滿級 65，否則等到跨等級再做**（例如 50→55 或 →60）。
為了一點點數值多賭一次詛咒不划算。（snA=1060）

### Q：寶石要怎麼弄？

```
① 紅寶石/黃玉/藍寶石/紫水晶/祖母綠 選 3 → 三重石英
② 鑽石 + 黑曜石 → 暗光石
③ 三重石英 + 暗光石 → 星光稜晶  ★終極目標（3 個選項，最高數值）
```
- **寶石晉階 100% 成功**，只是要時間累積
- **每天記得買商城道具商店裡用金幣賣的「破碎寶石寶箱」**
- 異種合成需要「粗糙的」階段以上
- 重洗標籤用**寶石技能雕琢器**（會把已有魔法效果一併重設）

### Q：寶石該挑什麼標籤？

看你**主力輸出技能帶什麼標籤**（強擊／連擊／元素／移動／生存／召喚／輔助／干擾）。
查 `../data/技能與標籤-全職業.md`，或遊戲內點頭像 →「戰鬥技能」。

## C. 職業

### Q：選錯職業怎麼辦？

**不會錯。** 職業可以自由切換，**等級與經驗值全部保留**。
只要持有該職業的**武器或徽章**，在 `[個人檔案] → [職業]` 就能換。
- 見習狀態只能換見習；轉職後才能換轉職職業。
- 其他職業徽章：杜巴頓學校－阿蘭雯，用職業大師勳章買
- 其他職業武器：武器店／鐵匠鋪／交易所

而且 `千把劍` 需要 6 個用劍職業到 40 級 ⇒ **多練職業本來就是必要投資**，不是浪費。

### Q：新手推薦什麼職業？

- **想輕鬆／自動戰鬥穩** → 修道士、冰霜術士
- **想好進隊** → 冰霜術士、戰士（有「破防延時」，全遊戲只有 3 職業有）
- **想高上限、願意練操作** → 戰士、劍術士、盜賊

### Q：一角多職 還是 多角色？

**兩個都要做，目的不同：**
- **一角多職** → 推職業等級，吃 `千把劍`、`領悟`
- **多角色（每帳號可額外開 5 隻，共 6 隻）** → 衝**累積職業等級 → 持有效果稱號**（全帳號永久加成）

## D. 日常與資源

### Q：每天該做什麼？

1. 野外首領 ×4 時段（12:00 / 18:00 / 20:00 / 22:00）
2. 週幾地下城（每天 1 次）
3. 黑色坑洞（每日 1 次探險 + 超額 7 次/週）
4. **通往深淵的黑色坑洞（不消耗探險次數，能刷就刷）** — 需先通關深淵「入門」至少 1 次；各狩獵場每個週期首次通關可拿**具持有效果的稱號**
5. 亡靈之塔 20 次（免費）
6. 不祥的召喚結界（每小時）
7. 用完銀幣（每 30 分回 1，**滿 100 就停止回復，別讓它溢出**）
8. 用完魔族貢品（每 12 小時 1 個，**滿 10 就停**）
9. 商城買破碎寶石寶箱
10. 掛自動採集

### Q：每週該做什麼？

1. 深淵「非常困難」，**通關戰利品每週 3 次**用滿（隊伍**復活次數上限 4 次**）；領上週每週戰利品（⚠ 沒領就不能再進深淵）；用深淵的化石找茉莉兌換
   （每週一上午 6:00 初始化；深淵 7/29 實裝，首次初始化為 2026-08-03）
   官方建議戰鬥力：入門 14,337／困難 16,358／非常困難 18,380
2. 野外首領討伐戰利品 3 次
3. **魔物討伐證明買滿**：遙遠的星辰印章、紫色催化劑
4. 兼職全清
5. 黑色坑洞超額 7 次
6. 團隊副本（格里斯貝恩）1 次

### Q：怎麼自動採集？

`[選單] → [圖鑑] → 冒險日誌支援品 → 寶物材料箱 → 選一個「稀有黃金系素材」`
系統會一直採到湊滿 10 個那個稀有素材為止——因為稀有素材難出，等於長時間掛機。
- 藥草 → 四葉草｜羊毛 → 黃金羊毛｜採礦 → 黃金碎屑｜撈水 → 黃金四葉草
- 伐木／昆蟲 → 黃金金龜子｜香菇 → 黃金苔蘚｜收割 → 黃金莖桿｜釣魚 → 黃金魚
- ⚠ **黃金系素材千萬不要分解或賣掉**
- ⚠ 自然淨化要**黑色團塊累積夠多**才會消耗聖水給獎勵，團塊少時不會觸發
- ⚠ 掛之前**多帶幾把工具**（會消耗耐久）

### Q：金幣怎麼賺？

狩獵場「黃金堆」＞ 閃耀洞穴（週一/四）＞ 交易所 ＞ 特殊兼職／幸運機會兼職。

## E. 賽季

### Q：新賽季會不會把我的東西清空？

- **官方尚未公布台服的賽季政策。**
- 依韓服經驗：新賽季**推出更高世代的符文**（S1、S2…），數值更高 ⇒ 舊符文被淘汰。
  ⚠ 這是**社群依韓服經驗的推測，非官方說法**。官方尚未公布台服賽季政策。
- **會保值的**：持有效果稱號、職業等級、寶石、生活技能、刻印強化點數（換符文時會轉移，但顯示階段可能變動）
- ⇒ **S0 的資源優先投在會保值的東西上。**

### Q：現在該不該課金？

社群兩派：
- 反對（snA=495）：內容不足、更新慢、RNG 套 RNG、無預警新賽季
- 支持（snA=1125）：「裝備系統在課金與無課玩家之間的平衡，是今年玩過的遊戲裡做得最好的」

**中立建議**：先玩到 65 級並打過深淵，確認自己還想長期玩，再考慮。
若要課，優先序：**生活會員（特殊兼職）＞ 階段性禮包 ＞ 幸運箱**。
CP 值試算見 snA=1324。

## E2. 社群黑話對照 ★

玩家在頻道／組隊時用的縮寫。看不懂會誤解對方在講什麼。

| 說法 | 意思 | 要注意的地方 |
|---|---|---|
| **DECA／德卡** | ⚠ **有兩個完全不同的意思** ① Death Count＝**剩餘復活次數**（深淵、團隊副本用）② 交易所貨幣**德卡** | 有人在深淵問「你還剩幾 DECA」是問**復活次數**，不是問你有多少錢。這是最常見的誤會 |
| **破防（브레이크）** | 填滿對方破防量條後進入的狀態 | 破防中的敵人會吃到「**無防備**」判定 ⇒ **全隊傷害都會提高**。能延長破防狀態的職業在組隊時特別受歡迎 |
| **黑洞／深洞** | **黑色坑洞／深層坑洞**（狩獵場內隨機出現的迷你地下城） | 見 `06-副本深淵與作業循環.md` §3 |
| **跑兩場（두탕）** | 一輪內連跑兩場**不祥的召喚結界** | 結界每小時開一次，怪的順序固定是 **地獄犬 → 術士(首領) → 米米克** ⇒ 頻道喊「地獄犬」＝還趕得上，喊「米米克」＝術士已經死了 |
| **攻增／傷增** | 「攻增」＝**攻擊力 +%**；「傷增」＝**對敵傷害 +%**。⚠ **這是符文的「固有能力」，不是詞條** —— 詞條的攻擊池 11 選裡**沒有**這兩項（見 `../data/官方機率表.md`） | 兩者落在**不同乘區**（同區相加、跨區相乘），所以**哪一區低就補哪一區**，不要全押同一種。機制與計算見 `01-核心系統與戰鬥名詞.md` §2.6 |
| **찐피증／짭피증**（真傷增／假傷增） | 韓服用語。有些符文**寫著傷害增加、實際卻以攻擊力結算**（已知：決鬥、安定） | 看到「這顆是不是假傷增」是在問這個。**不能只看字面**，台服是否修正未知 |
| **傳裝／傳寵** | 傳說時裝／傳說寵物 | — |
| **時裝票／寵物票** | 抽時裝與寵物的票券，另有「高級」版本 | — |

## E3. 戰鬥力卡住了怎麼查 ★

按這個順序自查，通常在前三項就找到問題：

```
① 性能改善做了沒？
   → 獎勵／秘術骰開到的高數值裝備，有沒有注入到身上那件？
     （鍊金術 → 性能改善，選有「讚」圖示的那個）
② 符文星等夠不夠？
   → 看顏色與星數，還在用低階的就拿去晉階
③ 每個插槽都鑲寶石了嗎？
   → 武器／防具各 3 孔、徽章／飾品各 1 孔，別留空
④ 選單 → 成長指南 → 「內容」頁籤
   → 沒打勾的就是你漏掉的每日／每週目標
```

> ★ **「等級」本身就是最強的規格。** 升級能選升級卡、副本獎勵隨等級變好、能穿更高等的裝備。
> **新手第一優先永遠是把主線推完**，不是研究配裝。

### ⚠ 帳面戰鬥力會騙人

**符合職業的有效配置，實際輸出上限可以差 2 倍以上。**
換成星數更高但詞條不對的符文，帳面數字上升，團隊副本貢獻度反而直接掉出前段。

但也不用矯枉過正：**新手期為了過內容的戰鬥力門檻，帳面數字也有它的價值。**
⇒ **先用高星符文過門檻，之後再把詞條調成實戰有效的。**

### 「強化名點」是迷信

玩家間流傳「找某個鐵匠比較好強化」「投硬幣看煙火占卜」「大教堂祈禱後再強化」之類的說法。
**這些說法彼此互相矛盾**（同一個 NPC 有人列第一名點、有人列黑名單），
**官方也從未公布任何 NPC 會影響機率的機制。**
⇒ 被問到就直接說是迷信，不要跟著推薦。

回答前確認：

- [ ] 有沒有搞混《瑪奇 Mobile》（手遊）和《瑪奇》（PC）？
- [ ] 有沒有問清楚是哪個職業？
- [ ] 有沒有把符文推薦講完整（武器／防具／飾品×3／徽章）？
- [ ] 有沒有一併給「該洗什麼詞條」和「技能強化該洗哪幾格」？
- [ ] 引用的東西是不是韓服 S1/S2 才有的？有沒有標註？
- [ ] 給了具體數字（機率、星級、%、保底次數）還是只說「機率不高」？
- [ ] 有沒有說明這是官方資料、社群實測、還是韓服搬運？
- [ ] 攻略文有沒有附 `snA=` 或連結讓使用者自己查證？
- [ ] 資料時點是 2026-08。現在是不是已經過很久了？有沒有提醒使用者？
